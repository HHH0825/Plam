# 猫爪会员维护工具

这是电脑本地管理工具，只监听 `127.0.0.1`，不是小程序页面。用于向指定账户追加、查询和撤销赠送会员，不伪造支付订单。

## 打开

在项目中双击本目录的 **打开会员维护工具.cmd**。现有项目Python环境可直接使用。

如果使用单独解压的维护工具包，先安装Python 3.10或以上版本，再双击 **首次安装并打开.cmd**；此入口只在工具目录创建Python环境并安装依赖，需要网络。以后直接双击“打开会员维护工具.cmd”。

## 首次连接

先部署本次配套的新版 `palm-api`，再使用赠送功能。不要将旧版退款处理代码与新赠送记录混用。

1. 环境ID填写你当前小程序使用的 CloudBase 环境。
2. 数据库实例、数据库名称照抄 `palm-api` 当前的 `CLOUDBASE_DB_INSTANCE`、`CLOUDBASE_DB_NAME`；原来为 `(default)` 时保持默认即可。
3. 管理员 API Key 填写 CloudBase 数据库管理员凭据，对应 `CLOUDBASE_API_KEY`。不要填微信 AppSecret、虚拟支付 AppKey 或通知口令。
4. 点击“连接”。输入框会清空密钥；下一步成功查询账户才表示数据库权限已验证。

凭据仅驻留当前工具进程，不保存到文件、浏览器存储或日志；关闭工具或闲置30分钟后清除。若凭据过期，在CloudBase生成新的管理员凭据后重新连接。

## 赠送／延长

1. 手机上进入 **我的 → 个人设置 → 用户ID → 复制ID**。
2. 在工具中粘贴ID，点击“查询”，核对环境、昵称和编号。
3. 选择1、3、12个自然月，或自定义1—3650天，填写操作原因。
4. 点击“预览赠送／延长”，核对当前到期日和操作后到期日。
5. 点击“确认执行”。已有会员从当前到期日后追加；未开通或已到期的账户从本次操作时间起算。
6. 手机上重新进入猫爪会员页，读取服务器最新身份。

每次延长也是一笔独立赠送。无需再支付0.01元验证普通会员功能；验证真正的支付链路仍需要手机付款测试。

## 撤销

查询账号后，在对应赠送记录旁点击“预览撤销”，填写原因，再核对变化后的到期日并确认。只撤销选中的记录，其余赠送和付费订单保留。有效授权会按原顺序重新计算，所以最终到期日可能提前；存在其他付费权益时不会强制变为免费。

## 遇到未确认或冲突

- 显示“操作未确认”时，保留当前预览，点击“重试同一操作”；同一编号不会重复增加时长。
- 显示“记录已更新”时，重新查询、预览，核对新的到期日后再确认。
- 如果关闭页面或预览已过期，先重新查询赠送记录，按操作编号和原因核对，不要直接再赠送一次。
- 旧会员基线校验失败时，工具会停止写入；保留原数据并核对订单，不手工覆盖会员到期日。

操作完成后点击“关闭工具”。本工具没有全量用户列表，不提供修改已支付订单、删除付费时长或跳过微信核单的功能。
