# 首页与物品卡片修订记录 · 2026-10-08

## 实施结果

- 首页显示“我的物品”、实际物品数量和小猫点缀；搜索、筛选、排序、档案／照片墙切换集中展示。
- 保留原纸片“新增”素材与组件，原生按钮完整接收点击。已在微信模拟器点击，进入 `pages/editor/index` 的空新增页，并返回首页；没有提交物品。
- 底部“物品／发现／我的”的配置、图标、颜色和选中样式保持原样。打开筛选时暂时隐藏原生导航以露出面板，关闭后恢复。
- 档案卡片使用 82px 缩略图、两个主要指标、细分隔线和 16px 圆角；列表省略购买价／天，详情及账目计算保持原样。处置物品显示“曾持有”，负数与缺失日均值按已有数据展示。
- 筛选使用独立草稿；确认后更新清单，遮罩或关闭按钮取消草稿。重置仅清空草稿状态与分类，保留搜索词。关闭页面及账号变化会丢弃草稿；分类刷新时按分类名称匹配，避免序号移动选错分类。
- 照片功能保持启用。真实水杯照片在档案与照片墙均成功显示；失败重试入口仍在图片下方，使用 `catchtap` 防止误跳转。
- 微信原生按钮默认宽度与离线浏览器不同，已通过明确工具栏宽度及筛选选项的原生 `mini` 尺寸修正，并实际截图确认。
