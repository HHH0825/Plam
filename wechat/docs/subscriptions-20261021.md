# 订阅／分期直观添加与记账删除联动（2026-10-21）

## 已实现

添加表单先选“订阅续费／分期还款”。订阅填写名称、每期费用、周期、下次付款日；分期填写名称、本金、期数、首期还款日，默认免息，打开开关后才填每期额外费用。关联物品、服务有效期、备注收在“更多选填”。新计划默认管理中，编辑已有计划保留类型与状态设置。

实时摘要按分计算分期本金和最后一期尾差。付款安排和服务有效期分开；本金计入真实记账支出，但不再次加入关联物品购买成本。切换类型保留各自输入，原草稿存储键保持不变。

新增时可选择“本期已经付了，顺手记一笔”，默认关闭。支持核对实际日期、费用、本金与合计；日期不晚于北京时间今天。不启用该选项只保存计划。尚未启用记账时须明确确认启用；取消可仅保存计划。旧服务端不支持时仍能保存普通计划。

首笔的建计划、启用记账、付款和记账使用同一事务。前端在发送前保存本次请求标识，超时后锁定原提交内容，重试核对同一次操作。离开页面不会取消已发请求；换账号不接收旧账号响应。超过安全重试期不自动重建；仅返回计划 ID 而缺少付款确认时读取该 ID 核对，不自动补付。

记账详情的订阅／分期自动支出新增“删除这笔账目”。确认后同步作废对应那一次付款、重算费用和本金进度，保留计划、其他付款、手填服务有效期和变更历史。两个入口共用服务端逻辑。有关联有效退款时阻拦，先处理退款。旧后端未提供 deletable 时仍保留“查看原记录”。返回订阅详情会重新读取进度，记账、预算、物品展示缓存随成功写操作失效。

## 配置与上线顺序

建议版本号 1.0.2。版本描述：优化订阅与分期添加流程，可同时记录首笔付款；支持在记账中删除对应付款并同步更新进度，保留原计划和历史记录。

1. 若已经更新本次 palm-api，云端无需再次更新；只需重新下载本目录最新前端 ZIP，替换本地前端后重新编译。仍报旧行号时，清除开发者工具“编译缓存”后重编译；不要清除用户业务数据。尚未更新后端时，再执行下面第2—4步。不要只替换单个页面。
2. 对 palm-api 现有云函数代码与配置做备份。将本次新目录内的 palm-api ZIP 用作现有 Python 3.10 HTTP 云函数的代码更新。继续保留现有启动方式、内存、超时、环境变量与权限。ZIP 根目录包含 app.py、palm/、third_party/ 和可执行 scf_bootstrap；不要再包一层目录。
3. 本次只需更新 palm-api，palm-api-bridge 不用更新。没有数据库迁移、索引、集合、环境变量调整。依赖沿用上一版已固定的 Linux 依赖。
4. 更新后用隔离测试账号读取 /auth/me，确认 capabilities.fixed_expense_quick_add 为 1。核对一次新建首笔付款、退款阻拦、从记账删除及返回计划后的进度。未确认能力前，前端会禁用同时记首笔的选项。
5. 上传新版前端体验版，安卓与苹果真机确认：分包首次进入、两种表单、放大字号、键盘、首次启用记账确认、保存失败重试、返回刷新、两处撤销入口。确认后由用户自行提审发布。
6. 升级后如回退前端，已保存的付款和逻辑作废记录仍保留；后端回退前应先核对新客户端能力和进行中的请求，不能通过再次提交“补记”不确定结果。
