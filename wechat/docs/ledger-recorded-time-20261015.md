# 记账精确新增时间 · 2026-10-15

## 已完成

- 记账流水、统计当天流水增加“记录于 YYYY-MM-DD HH:mm:ss”。账单详情分开显示“收支日期”和“记录时间”，退款记录显示自身记录时间。
- 复用服务端已有 `created_at`，客户端按时间戳中的时区换算为北京时间，显示到秒；微秒直接截取，不四舍五入。未增加时间输入框。
- 修改、作废、关联退款和重试不使用 `updated_at` 覆盖创建时间。补记日期、月份归属、排序和统计保持原规则。
- 缺失、无时区或非法创建时间显示“记录时间暂不可用”，不从收支日期拼接零点时间。
- 日期与时间可分行，时分秒不拆开；新增文字沿用灰色辅助信息样式，不影响整行点击和金额区域。
- 无新增接口、字段、数据库迁移或后端业务代码修改；不需要更新服务端。未部署、未上传体验版，也未使用 Computer Use。

## 接口与使用

继续使用账目查询、详情及退款中已有的ISO时间戳 `created_at`。字段须包含明确时区，例如 `2026-10-15T06:08:36.123456+00:00`，展示为 `2026-10-15 14:08:36`。

微信开发者工具重新编译客户端后即可查看；已有记录有合法创建时间时立即显示。没有创建时间的旧记录保持“暂不可用”，不回填虚构时间。

真机字体、安全区、实际点击与微信设备布局未测；本轮未修改此前其他视觉问题。
