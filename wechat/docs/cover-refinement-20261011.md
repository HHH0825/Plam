# 图标反馈、完整金额与波点增强

实施起于2026-10-11，验证补齐于2026-10-12。仅修改客户端、本地素材和说明。

## 已实现

- 图标弹层关闭按钮相对弹层定位，顶部、右侧各12px，严格44×44px；叉号使用两条圆角线绘制，不受字体或原生按钮默认宽度影响。标题为按钮预留空间。
- 底部固定区包含确认、微信原生反馈按钮和填写提示。全部分组、搜索与无结果状态共用同一底部；反馈返回保留搜索、分组、待选图标和表单。
- 搜索框关闭平台自动推移，按键盘高度和当前窗口实际高度计算弹层高度及底部偏移；窗口已经缩小时不重复扣除键盘高度。图标网格独立滚动，底部安全区域继续占位。
- 用户通过微信原生页面提交图标名称、用途和参考图；作者登录对应AppID的小程序管理后台，在“客服反馈／用户反馈”中查看。不会自动带入搜索词，不承诺实时通知，不新增反馈接口或数据库集合。详见[反馈说明](feedback.md)。
- 持有列表与已处置档案共用测量：一次批量读取可用区域与隐藏文字的实际宽度，依次尝试24、22、20px；不足时整组纵排，再不足时移到图片下方。窗口变化、搜索筛选和数据刷新时重新测量；旧账户或旧刷新回调不得应用布局。
- 详情日均金额依次尝试28、26、24px，必要时整体纵排。金额与单位不拆行；极端数值仅在金额行横向查看，数据未截断或简写。累计净成本同样可横向查看，并按实测文字高度留出空间。
- 全局波点保留240px无缝图案与原错落位置，黄色改为`#FFE59A`、粉色改为`#F4CCD9`，直径约4–6px。黄色占四分之三。更新后的透明PNG为2235B，内嵌样式3207B，低于10KiB预算。SVG源文件保留于`branding/page-dots-20261011/`。
- 白色卡片、输入框、弹层、微信原生栏和导出图片保持干净；底部导航行为、金额精度及后端计算不变。

## 验证记录

- 客户端58项通过：新布局选择与旧测量隔离、键盘高度计算，以及封面选择、草稿、持有／已处置范围、详情和照片提交回归。校正原收藏列表测试中的旧假设：照片缓存接收完整的已装饰数据，费用字段仍保持原响应值。
- 离线布局48组通过：320、390、430、768px，覆盖列表、已处置档案、详情、登录、我的、图标弹层、大字体、无结果及缩短可用窗口。检查无页面横向溢出、无失败素材、叉号位置与尺寸、反馈声明和底部可见性。
- 金额示例包括`1999.00`、`999999999.99`、负值、零值、“暂无”、长天数和超长极端值。可视数字始终为同一行，超出整卡宽度时使用横向容器，不改变金额字符串。
- 微信模拟器16项检查通过，使用拦截云请求的隔离数据，验证关闭定位、反馈点击范围、无结果、返回状态、键盘事件、列表／详情／已处置金额布局。过程不向真实账户写入，不自动提交反馈，结束后恢复原账户、请求方法并清理隔离草稿。证据见`images/cover-refinement-20261011/native-results.json`。
- 键盘场景为模拟器注入300px键盘高度事件及离线缩短窗口检查；不等同于手机系统输入法验证。反馈返回为页面生命周期检查，不等同于真实反馈提交、后台接收验收。
- 真机iOS、Android、小米K80 Ultra、系统大字体、真实输入法及真实反馈提交／后台接收待补核。
