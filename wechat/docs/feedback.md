# 反馈与支持作者

## 用户怎么反馈

在“我的”点击“反馈与建议”、在“支持作者”页点击“提个建议”，或在物品图标弹层底部点击“没有找到想要的图标？告诉我”。这些入口都使用微信原生 `button open-type="feedback"`，由微信打开意见反馈页面，用户填写并提交。点击入口不代表已经提交。

图标需求建议写明物品名称、用途，并附参考图片。图标弹层中已选图标、分组、搜索词和物品表单在返回后保留；这些内容不会自动填入微信反馈，也不会自动提交。作者在下述微信后台查看图标需求，不通过本地开发控制台或新增数据库集合接收。

反馈不会写入猫爪物帐的 SQLite 数据库，不需要开启新的 Flask 接口。“支持作者”是一页感谢说明，目前没有付款、金额选择或收款码。

## 作者在哪里查看

1. 用该小程序的管理员或有权限的运营账号登录 [微信公众平台](https://mp.weixin.qq.com/)，选择与项目 AppID 对应的小程序。
2. 在左侧菜单找到“客服反馈”，查看用户反馈内容。如果后台菜单改版，查找“用户反馈”或使用后台帮助定位；不能在本地 Flask 控制台看到这些内容。
3. 在手机微信中提交一条带日期的测试建议，然后回到后台核对是否收到。测试号、开发者工具模拟页面不能替代这一步。

原生入口能力参见 [微信官方 button 文档](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)；官方示例仓库也记录了 [反馈与后台查看方式](https://github.com/wechat-miniprogram/miniprogram-demo/issues/5)。本功能不承诺实时推送通知，作者需要自行查阅后台。

## 验收状态

已完成原生入口声明、作者页打开与返回、页面编译及相关前端测试。独立项目中点击“提个建议”会打开微信反馈页面（电脑上由浏览器显示“请选择反馈类型”），未填写或提交测试内容。真实手机提交、后台接收和 Android／iPhone 的反馈页仍待项目负责人验证。正式版本需要使用自己的 AppID 和微信认证配置；电脑本地模拟登录仍只用于本机开发。
