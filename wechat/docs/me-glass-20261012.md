# “我的”页奶黄背景与玻璃概览

## 实现

- 采用已确认的奶黄装饰草图（源图保存在 `branding/me-glass-20261012/approved-sketch.png`）。上半部为 `#FFF7E0`，背景随头像、概览、说明及错误提示的实际高度伸缩，并在概览下半部至说明附近淡入白色。平板背景铺满窗口，内容继续沿用原有最大宽度。
- 删除虚线和中央猫爪分隔及其70px布局占位；说明与“我的收藏册”之间恢复原有16px标题间距，不新增过渡空白带。
- 两组原创猫爪、月牙、星星、爱心和手绘短线使用透明PNG，位于头像两侧，不增加高度、不接收点击；装饰底边位于昵称上方。SVG和参考图不进入小程序包，PNG合计9797B。
- 复用现有波点纹理，放在奶黄底上、玻璃层后；背景图案不盖住文字，其他菜单卡片保持干净。
- 概览使用独立玻璃底层：55%乳白、16px背景模糊、115%饱和度、细白亮边、轻微高光及阴影。数字和按钮位于清晰的内容层。标准及WebKit属性同时声明，不支持时95%乳白回退。
- 保留三列及大字体布局切换、金额缩写与精确金额弹窗、加载／错误／旧后端状态、菜单顺序、浅粉退出按钮和底部导航。本轮没有修改页面业务逻辑或公共接口。

## 验证

- 32项相关测试通过：金额字符串精度、边界、布局测量、旧后端、失败重试、账户隔离、个人资料、退出行为与配色回归。
- 96组离线布局通过：320／390／430／768px，普通与1.3倍文字；320px同时为640px短屏。覆盖正常金额、完整金额、零、亿元进位、极端金额、弹窗、加载、旧后端、统计错误、长昵称和资料错误。
- 检查金额单行及高度、44px金额点击区、波点与奶黄背景、背景随内容伸缩、装饰与昵称分离、分隔线移除及退出按钮滚至末尾无遮挡。
- 微信模拟器14项外观、布局、金额弹窗、错误重试、旧后端及账户清除检查通过；另2项独立个人设置与禁止写入检查通过。结果分别见 `native-results.json` 与 `native-settings-results.json`。使用内存演示账户拦截请求，完成后恢复原账户和请求方法。模糊、关闭模糊和95%乳白回退在同一位置截图；另以静态彩色条纹作为隔离背景对照。开启后卡片后的条纹融合成柔和色块，关闭后仍呈现清楚条纹，数字始终清晰。条纹仅是验证开关，正常页面不启用，也不用于模拟模糊。截图内同一无文字区域的相邻像素变化由关闭时2.342降为开启时0.159，回退为0.513，见 `glass-pixels.json`。
- 组合原生流程在手动模拟账户生命周期后立即点击个人设置，跳转断言未通过；该次记录保留 `passed:false`。新打开的独立页面点击个人设置通过。业务导航逻辑未修改，不将这次组合流程算为完整通过。
- 静态打包检查通过136处素材引用；按已有忽略规则计算运行文件未压缩合计1029228B，这不是微信上传后的压缩包大小。
- 真机iOS／Android、系统字体设置与真实触摸手势尚未实测。1.3倍文字、平板和短屏为离线布局验证；既有模拟器个人资料自动返回问题不在本轮样式修改中修复，不宣称该返回流程通过。
