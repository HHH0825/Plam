## 交付状态

已实现客户端、SQLite 与 CloudBase 账本、物品付款联动、关联退款、历史核对与收支统计。**仅本地可审阅；未部署云函数、未上传体验版，未提交真实业务数据。**

当前微信项目仍使用原线上服务。只有服务端返回 `capabilities.cash_ledger:1` 后，客户端才显示开启／使用记账；旧服务端继续显示筹备提示，不会出现假保存成功。正式使用须先完成下述后端同步。

## 已实现功能

- 记账首页：月份切换、搜索、收付／分类／来源筛选、整月概览与独立筛选合计、日期倒序流水、分页、空状态和失败重试。
- 记一笔：支出／收入、独立分类、金额、北京时间日期、名称、备注、可选关联物品。账户隔离草稿、退出提示、版本核对；网络结果未确认时锁定原提交并提供查询／原内容重试。
- 账单详情：完整金额、来源、物品链接、分期拆分、退款列表、手动更正／作废；自动账目返回原业务。永久删除原来源后，账目和名称快照仍保留，可单独更正或作废。
- 退款：部分／全额、跨月冲减原分类，退款可改／作废，累计不得超原支出。有退款时保护原记录，失败整笔事务回滚。
- 新增／编辑物品及心愿转换：已付款／分期首付／仅建档；可选用同金额同日期的已有手动支出，避免双记。关联普通账目本身不增加物品成本。
- 维修、处置回收及订阅／分期实际付款联动；分期本金＋费用作为一笔实际支出，计划与完整购置价不重复入账。
- 历史核对：逐条确认、每批最多 20 条、跳过后可继续；购置必须确认付款方式，提交重查来源指纹。持久批次操作号和结果查询覆盖网络中断、重启及重复提交。
- 统计：同一本账的月概览、每日原支出／收入、退款金额、扣退款后的分类排行，以及现有物品分析入口。五入口导航与左右新增面板保留。

单笔金额沿用现有上限 999,999,999.00 元；整月合计以整数分计算、十进制字符串显示。仅支持人民币；本轮没有资金账户、转账、预算、自动扣款、账单识别。

### 统计口径

记账按实际收付；本月支出已扣当月退款。退款超过支出显示“本月退款结余”，净额按方向显示“本月净收入／净支出／收支持平”，金额为绝对值。普通收入不包含退款。

物品购买价格仍用于原物品成本；分期付款的本金不再次增加物品净成本。退款不自动改购买价或还款进度。小小发现、收藏小报、导出及日均净成本均保留原口径。

## 接口与迁移

详细接口、请求示例、版本、退款和幂等规则见 [接口说明](cash-ledger-api-20261013.md)。

### SQLite

1. 停止本地服务，备份当前数据库及照片目录。
2. 使用本轮后端启动。初始化自动迁至 `user_version=13`，新增 `ledger_entries`、`ledger_settings` 及物品可空 `payment_info`。
3. 旧库首次升级先生成 `<数据库名>.pre-ledger.bak`；保留用户、物品、照片和旧成本数据，不自动补账。
4. 以隔离测试账户开启记账、核对历史、确认保存及退款后，再用于正式记录。

### CloudBase

备份现有函数版本和配置，增量资源清单在 [resources-delta.json](../deploy/cloudbase/cash-ledger-20261013/resources-delta.json)，`applied:false` 表示未应用。

| 集合 | 索引 | 访问权限 |
|---|---|---|
| `palm_ledger_entries` | `user_id, _id` 升序、非唯一 | 仅服务端，拒绝客户端直接读写 |
| `palm_ledger_settings` | 使用现有 `_id` 索引 | 仅服务端，拒绝客户端直接读写 |

物品文档按实际提交增量保存 `payment_info`；旧记录无需批量回填。沿用已有身份、计数器、回执、物品、维修、处置、订阅及付款集合与索引。

部署顺序：创建增量集合并核对权限 → 更新 Python API → 如启用 Node 桥接则同步桥接 → 隔离账户验证 → 更新客户端。直连模式客户端路由白名单已更新；无新增密钥、运行依赖或定时任务。

| 本地包 | 用途 |
|---|---|
| [palm-api-python310.zip](../deploy/cloudbase/cash-ledger-20261013/palm-api-python310.zip) | Python 3.10 Linux API，包含运行代码与既有锁定依赖 |
| [palm-api-bridge-node20.zip](../deploy/cloudbase/cash-ledger-20261013/palm-api-bridge-node20.zip) | 可选 Node 20 桥接 |
| [manifest.json](../deploy/cloudbase/cash-ledger-20261013/manifest.json) | 来源文件哈希、依赖基线、包体及 SHA-256 |

包内不含数据库、照片、凭证或真实用户数据。复现：`wechat/.venv/Scripts/python.exe wechat/tools/prepare-cash-ledger-release.py`。先保留已有后端版本与新集合再回退，不通过删库／删集合回退；记账期间已有收付必须保留。
