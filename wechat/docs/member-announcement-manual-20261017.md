# 会员公告与年会员停售：中文操作说明

本次交付包含新版小程序前端和 `palm-api`。尚未自动部署、发布、修改真实会员或发起付款。请把这份说明与本次更新包配套使用；旧说明中的年商品配置不再适用于新版。

## 更新后的效果

- 会员页恢复紧凑的标题与猫咪插画，原留言气泡移除。身份信息旁增加“公告”，可随时重新查看。
- 每个账号在本机首次成功读取公告后自动弹窗。点右上角关闭或“我知道了”才记住；点遮罩不会关闭。正文可滚动，反馈入口固定在窗口底部。
- 关闭后再次进入不自动弹出；换账号独立记录，换手机或清理小程序缓存后可能再次出现。存储失败时，本次会话也不会反复弹出。活动结束后，过期特惠文案不再显示，反馈说明仍可查看。
- 只销售月会员、季会员，默认选月会员；有效会员仍显示“已拥有”，禁止重复新购。已有年会员的有效期不缩短，历史年订单继续查单、补发、去重和退款。
- 维护者工具的“赠送12个月”是独立的赠送时长，按确认继续保留，原工具无需因本次停售而更新。

## 一、先准备并验收前端

1. 保存当前已部署的 `palm-api` 包和小程序工程备份，不清空数据库。
2. 将 `catpaw-miniprogram.zip` 解压到新的文件夹，用微信开发者工具导入含 `app.json` 和 `project.config.json` 的目录，保持原 AppID、云环境和传输配置。
3. 本地编译，扫码预览公告开关、月季两张卡及已有会员日期。此时先不删除旧环境变量，先安排好后端更新与前端上传、提审和发布时间。
4. 新前端会过滤旧服务返回的年套餐；新服务端会阻止旧前端新建年订单。无法同时更新时，旧页面可能短暂保留年卡，但点击会提示套餐停售；不要让用户重复尝试付款。

## 二、上传 palm-api，再发布配套前端

1. 在现有 CloudBase 环境打开 **palm-api**，上传同目录的 `palm-api-member-announcement-python310.zip`，仅更新函数代码。
2. 保留原入口、Python运行环境、权限、网络、超时、支付密钥和消息配置。**不要把此包上传到 palm-pay-notify**。本次通知函数和定时补单任务不需要更换或关闭。
3. 先保留原环境变量，确认新版函数生效：会员目录只返回月、季；年会员新购返回 `410 / PLAN_RETIRED`，不会创建订单。
4. 用扫码预览的新版前端核对月季目录与会员身份，然后由你上传、提审、发布小程序。已发布用户关闭并重开小程序加载新版；旧版本年会员购买请求会被服务端拒绝。
5. 如果你的工程仍用旧 `cloud_function` 桥接传输，本次公开接口地址和请求形状未变，无需为本次功能替换桥接代码；当前工程的 `cloud_http_function` 也无需桥接更新。

## 三、你要手动停售／删除什么

### 公众平台的两个年商品

在“虚拟支付 → 基本配置 → 道具配置”中按道具ID查找，或在平台当前对应的商品管理页查找：

| 终端 | 停售道具ID | 原金额 |
|---|---|---|
| 安卓 | `catpaw_vip_year` | ¥29.90 |
| 苹果 | `catpaw_ios_year` | ¥33.90 |

- 如果你实际使用了其他道具ID，以旧环境变量保存的真实值为准。
- 优先使用下架／停售并保留交易记录。后台没有对应操作或不允许删除时，保留道具即可；新版API已不允许创建年会员新订单。
- 有未决年订单时，先通过原订单核对状态，再做会影响原订单处理的商品操作；不能确认平台影响时先保留旧道具。不要删除或作废历史交易记录。
- 没有创建过苹果年商品，就无需处理它。不改月、季道具，不重新定价。

### palm-api 的两个环境变量

**必须在新版 palm-api 更新成功之后再删除**：

| 删除项 | 原用途 |
|---|---|
| `PALM_PAY_PRODUCT_YEAR` | 安卓年会员道具ID |
| `PALM_PAY_IOS_PRODUCT_YEAR` | 苹果年会员道具ID |

删除并保存配置后，再查一次两端月季目录与购买开放状态。旧API要求三档商品齐全，提前删除会造成月、季也不能买；新版已经解除这个依赖。忘记删除这两项也不会恢复年会员销售，新代码会忽略它们。

### 必须保留的配置与数据

| 保留配置 | 对应商品／作用 |
|---|---|
| `PALM_PAY_PRODUCT_MONTH` | `catpaw_vip_month`，安卓¥3.90 |
| `PALM_PAY_PRODUCT_QUARTER` | `catpaw_vip_quarter`，安卓¥9.90 |
| `PALM_PAY_IOS_PRODUCT_MONTH` | `catpaw_ios_month`，苹果¥4.50 |
| `PALM_PAY_IOS_PRODUCT_QUARTER` | `catpaw_ios_quarter`，苹果¥11.50 |
| 原支付开关、测试白名单、OfferID、密钥、通知鉴权配置 | 保持原验收通过的值，不照抄示例覆盖 |

完整示例见 `palm-api-env.example.json`，只供字段核对，不含你的真实密钥。若尚未通过苹果支付验收，继续保持原受控状态，不因本次改版直接向公众开放。

不删除订单、授权、会员状态、赠送审计、数据库集合或索引；不重置任何有效期。无需运行迁移，不新增集合或索引。旧部署包保留作备份；截图、日志和说明不上传进小程序或云函数。

## 四、手机验收清单

1. 未看过公告的账号首次进入自动弹窗；正文能滑到底，关闭按钮和“反馈与建议”均可点击。先关闭再退出重进，应不再自动弹出；“公告”能手动重开。
2. 页面先往下滚动，再打开并关闭公告，原滚动位置保持；底下的套餐和权益不会因公告开关上下跳动。
3. 换账号，会员身份和公告记录互不串用。读取失败时只显示失败和重试，不能显示旧公告或错误身份。
4. 安卓显示¥3.90／月、¥9.90／季；苹果显示¥4.50／月、¥11.50／季。原真实付款验收要求继续执行，本轮电脑测试不替代真机付款确认。
5. 有效会员两档均“已拥有”；原到期日期不变。查询历史年订单仍能看到原金额；原来待确认的年订单继续使用原订单核对，不另建订单。
6. 删除两项年商品环境变量后，月季购买开关不应被错误关闭。若仍未开放，检查原支付开关、测试白名单及月季商品配置，不要仅根据页面样式判断支付已经上线。

## 校验与回退

每个ZIP的SHA-256在同名 `.sha256` 文件及 `upload-manifest.json` 中；本地可用 `Get-FileHash -Algorithm SHA256` 核对。`验收截图`与`验收记录.md`包含结果及限制。

回退前先暂停新购买并检查前后端版本与商品配置。旧API仍依赖年商品配置，直接恢复旧API可能使全部购买关闭或重新出现年套餐；不要为了回退而未经核对恢复年会员销售。无需改动已有会员数据。保留原订单通知和补单，以便继续处理已经生成的订单。
