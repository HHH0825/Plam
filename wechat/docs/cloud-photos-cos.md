## 1. 创建专用密钥（请在腾讯云网页操作）

下述是已完成配置的复现步骤，不要求重新创建或扩权现有子用户和密钥。

操作入口及子用户 API 密钥获取方式依据[腾讯云授权子账号访问 COS 指南](https://cloud.tencent.com/document/product/436/11714)。

1. 打开 [访问管理 CAM](https://console.cloud.tencent.com/cam)，进入“策略 → 新建自定义策略”，选择策略语法/JSON 创建，名称填写 `palm-photo-prod-policy`。
2. 将 [受限策略](../deploy/cloudbase/cos-photo-policy.json) 的完整内容复制进去。它仅允许上海现有桶的两个照片目录；不要绑定 `QcloudCOSFullAccess`、管理员策略或用户组继承的额外权限。
3. 进入“用户 → 用户列表 → 新建用户”，创建专用子用户 `palm-photo-prod`，启用编程访问/API 访问，控制台登录无需开启。绑定上一步的唯一策略。名称是管理标签，可以按控制台规则调整。
4. 在该子用户的“API 密钥”页创建一对 SecretId / SecretKey；不要创建主账号密钥，不要把密钥发到聊天、提交到仓库或放入小程序。
5. 到现有 `palm-api → 函数配置 → 编辑 → 环境变量`，使用可视化输入增加下表。保留已有数据库、微信登录、存储桶和域名变量。

| 变量 | 值 |
| --- | --- |
| `PALM_COS_SECRET_ID` | 专用子用户的 SecretId |
| `PALM_COS_SECRET_KEY` | 同一对密钥的 SecretKey |
| `PALM_CLOUD_PHOTOS_ENABLED` | 先填 `0`，验收时才设 `1` |

COS SecretId 是签名中的身份标识，上传表单必须带它；SecretKey 始终只在服务端。CloudBase 管理员 API Key 继续用于数据库，不可替代这对 COS 密钥。每九十天轮换：生成新对 → 更新 Python 两个变量并重启/部署 → 验证新签名 → 等待旧上传和下载最长十分钟到期 → 停用旧对。COS 密钥不因这里的九十天说明自动过期。

## 4. 协议与失败处理

- `POST /api/mp/items/<id>/photo/uploads`：JSON `{size_bytes, content_type}`。类型为 JPEG/PNG/WEBP，大小 1..5242880 字节；正文只返回 `ticket, expires_at`。
- 上传授权在 `X-Palm-Photo-Transfer` 中，以不带填充的 base64url ASCII JSON 传递：`{v:1,kind:"upload",url,form,expires_at}`。COS 签名 POST policy 绑定准确桶、随机用户路径、声明类型、准确字节长度和原始十分钟截止时间。小程序 `wx.uploadFile` 的文件字段为 `file`，成功状态 204。
- `POST /api/mp/items/<id>/photo/uploads/<ticket>/commit`：JSON `{}`，重新验证会话、归属、有效期、实际大小/MIME/解码格式。正式图片 ≤512 KB/1600，缩略图 ≤80 KB/480；校正方向并清除元数据。两文件写完后才事务替换。最长等待 55 秒；取消或超时不承诺撤销服务器提交，重试使用原编号并先核对物品。
- `GET /api/mp/items/<id>/photo/download?size=full|thumb&v=<版本>`：正文仅含版本和到期时间；响应头 `{v:1,kind:"download",url,expires_at}`。实际 `q-sign-time` 和 `q-key-time` 均最多五分钟，固定 HTTPS COS 域名且文件路径必须匹配服务端归属。固定 SDK 1.9.44 将起始时间提前六十秒，因此传入 `Expired=240`：实际可用约四分钟，两个签名区间均为 300 秒；不是未经验证地传入 300 后假设符合要求。
- 去重回执只保存业务 JSON。凭证重试读取原上传记录重签，期限不延长；过期返回 410，已提交返回 409。签名不存日志、数据库回执、草稿或本地重试记录。SDK 诊断禁止输出请求头、响应头或异常全文。
- 返回头必须在开发工具和真机完整传递，并核对原生调用日志、函数日志是否记录签名。任一泄露或有效期不确定均停止启用，不能退回正文传签名。
- 暂存、失败新文件、替换旧文件进入已有持久清理队列。下载过期只限制再次访问；已下载到手机的内容不会因签名过期自动消失，缓存按用户及版本清理。
