# 全页波点与磨砂玻璃导航 · 2026-10-11

## 本地实现

- 所有15个页面共用纯白底上的淡黄 `#FFF1BC`、浅粉 `#FBE7EE` 波点。直径2.2–3.8px，240px图案中黄色12点、粉色4点，位置错落，无动画及点击层。
- 移除页面级背景重置，将登录、心愿、订阅、收纳的外层容器设为透明。卡片、输入框、菜单、统计框、退出按钮及弹层保留干净底色。微信原生顶栏、状态栏以及小报导出画布没有改变。
- SVG源文件和2倍PNG位于 `wechat/branding/page-dots-20261011/`，不进入小程序包。运行时只内嵌一次压缩PNG：图片1455B，完整共用样式2167B，低于10KiB目标。
- 导航几何尺寸、黄色猫爪、触摸区域、安全区域及原导航逻辑保留。独立材质层目前使用40%乳白底（首版58%）、20px模糊、120%饱和度，降低高光和阴影；文字及图标不模糊。
- 默认95%乳白底；标准或WebKit背景模糊特性查询命中后启用增强样式。组件的 `glassFallback` 与 `glassNoBlur` 默认为false，仅供同位置验证回退和无模糊对照，没有新增面向用户的设置。
- 背景模糊作用于元素背后的内容，需要半透明底色；特性查询仅证明语法支持，不能单独证明微信跨层取样成功。[MDN：backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)
