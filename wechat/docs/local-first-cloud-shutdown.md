# 纯本地版发布后的云服务关闭指引

2026-11-11更新：2.0.0纯本地版已由作者确认正式上线，取消过渡和自动迁移。作者于2026-11-08按控制台流程处理旧CloudBase环境，已展示“已隔离”与“释放环境”确认页；本仓库未取得释放完成及全部费用结清凭据，不据此宣称整个腾讯云账号下所有资源均已清空。下面保留关停与后续费用核对步骤。

1. 先保留管理员数据库、照片与必要配置备份，核对可读取。提前告知旧用户本地版不会显示旧云端资料，并说明数据处理安排；公告不能当成后台已经执行删除的证明。
2. 用真机验证纯本地版断网业务和备份恢复，审核通过、正式发布并确认运行正常后，再处理云服务。
3. 对照腾讯云费用中心账单列出实际收费资源。微信云开发与腾讯云CloudBase可能是同一环境的两个入口，以账号、地域、环境ID核对，避免误关其他项目。原项目环境ID记录为cloud1-example，实际操作前仍需在控制台核实。
4. 核对环境套餐、资源包、自动续费和按量计费；环境外独立COS、CDN、服务器等只按实际存在的资源处理。取消续费不等于立即停止按量计费，删除几个函数也不等于已经清理所有收费项。
5. 在备份确认、正确资源清单及用户明确关闭指令齐备后，按控制台当前计费模式销毁目标环境，逐项核对数据库、存储、函数和资源包。环境销毁会清除其数据，不能恢复；独立资源另行核对。不注销整个腾讯云账户代替项目清理。
6. 保留关闭回执，检查之后的用量、自动续费和账单，确认没有遗漏及尾部结算；退款与结算以实际控制台为准。

官方参考：[CloudBase环境销毁](https://cloud.tencent.com/document/product/876/40467) · [费用中心续费常见问题](https://cloud.tencent.com/document/product/555/12212)。实际关闭以控制台完成状态和后续账单为准；仓库源码更新不会创建、关闭或续费云资源。
