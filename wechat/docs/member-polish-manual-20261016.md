# 会员页面与手账外观更新操作说明（2026-10-16）

本轮只在电脑内完成代码、测试与打包，没有修改真实会员、发起付款或上传云端。本次更新目录是 `wechat/deploy/cloudbase/membership-polish-20261016/`，不要与前一份 `membership-dual-platform-20261016` 混用。

## 这次改好了什么

- “我的”会员工具默认收起，点击“会员工具 · 5项”展开；每个账号单独记住选择。
- 统计顶部为“账本选择／我的账本／自定义分析”，记账为“账本选择／我的账本／本月预算”，三列带小图标。预算摘要另放一行，长账本名在入口省略，选择列表显示全名。
- “会员装扮”更名为“手账外观”。四种配色、三种小报模板和猫咪贴纸可以预览；小报预览与真实导出共用生成逻辑。选择是草稿，点击“应用外观”才保存。恢复默认后也要应用。免费用户可试看，应用仍由服务端核验会员；到期使用默认外观，历史选择保留。账本封面仍在“我的账本”设置。
- 会员入口、订阅页有“初创特惠”和说明，截止为**北京时间2027年1月1日00:00**。截止后隐藏活动标签及活动说明，**价格不自动变更**。会员页保留微信反馈入口。
- 付费会员、赠送会员及两者叠加，都在有效期内显示“已拥有”，三档套餐均不可新购；到期后才可购买。购买记录和订单核对仍能用。旧版本也受服务端限制；旧订单已经付款的，仍正常核对、去重、发放权益。

## 一、先保留你目前的配置

1. 记下目前 `palm-api` 的环境变量、执行入口、版本及支付开关；可以在自己的电脑安全保存，**不要把密钥发到聊天里**。
2. 记下当前正在使用的小程序源码目录和云端函数代码版本，便于必要时恢复。
3. 本次没有新增环境变量、集合或索引。不删除、不重建数据库，也不重新赠送会员。

## 二、更新 palm-api（必须）

1. 腾讯云 CloudBase → 云函数／托管 → 函数管理 → **palm-api**。
2. 进入函数代码，以“上传 ZIP 包”的方式上传本次目录里的 **`palm-api-membership-polish-python310.zip`**。沿用上次的部署方式；不要解压后只传部分文件。
3. 沿用现有 Python 3.10 运行环境、执行入口、网络和超时配置。
4. **保留现有全部环境变量的实际值**。包内 `palm-api-env.example.json` 只是示例，不要整份覆盖，里面的空白密钥及开关不是你的线上配置。
5. 保存／部署代码并等待完成。这一步不会给账号赠送会员，也不会改变已有到期时间；新下单时会使用账户保护记录防止重复未决订单。

安卓原价仍为月3.90／季9.90／年29.90元；苹果为月4.50／季11.50／年33.90元。道具ID、白名单和两端开关沿用当前配置，公众平台本轮无需再改商品。是否开放收款仍按之前安卓、苹果真机和云端超时验收结果决定；本次页面更新不代表通过了那些验收。

## 三、更新小程序前端（必须）

如果微信开发者工具当前打开的就是本项目 `wechat/miniprogram`，本轮代码已在该目录，直接重新编译。若你用的是另一份源码：

1. 解压 **`catpaw-miniprogram.zip`** 到新的文件夹，避免覆盖自己其他源码。
2. 在微信开发者工具导入这个文件夹，确认是猫爪物帐对应的 AppID 和原来使用的云环境。
3. 沿用你已验证的本地私有配置。前端包不含 `project.private.config.json`，也不含管理员密钥。
4. 编译后先生成预览／体验版本。旧手机预览包不会自动变成新的源码，请重新扫码或打开新体验版。
5. 按下面清单验收后，再由你上传、提审、发布；本轮没有自动执行这些操作。

**先更新 palm-api，再体验新前端。** 仅更新前端不足以阻止旧版本下单；仅更新后端则旧前端还可能显示原来的提示。

## 四、你可以这样验收

1. 用已赠送会员的自己的账号打开“我的”：应为已开通会员证，旁边有初创特惠；会员工具首次收起，展开后有五个入口。
2. 收起／展开一次，离开再回来应记住状态；另一个账号不应继承你的选择。
3. 打开统计、记账：顶部三个入口同一行，均能点开；预算金额在下一行。
4. 打开“手账外观”：切换四种配色、三种模板和贴纸，分别看页面效果、收支小报、收藏小报。未点应用时返回应提示；点应用后记账／统计／导航及实际小报采用相同选择。
5. 打开会员订阅页：你的有效会员应该所有套餐显示“已拥有”，主按钮不能支付，并显示到期日期及“到期后可再次购买”。**这时不用再付一次钱来测试。**“购买记录”和“核对待确认订单”仍可使用。
6. 免费账号应能预览手账外观，但应用时需要会员。不要为了验收到期／退款而撤销真实付费权益；这些交错情况已使用隔离数据验证。赠送的测试身份可通过维护者工具按原流程逐条撤销。
7. 活动按服务器时间判断。2027年1月1日00:00后标签和活动说明消失，价格不自动上涨；改手机日期不应用来模拟服务端截止。

## 五、另外两个包怎么处理

- **`palm-pay-notify.zip`**：与上一份双端版本的通知代码一致。若你已经按上次说明部署成功，本轮无需重复上传；也不用重配消息推送和定时器。
- **`palm-member-maintainer-windows.zip`**：同一维护者工具，附带当前后端代码。可以解压到新的目录继续使用，管理员凭据仍只在当前进程中保存。原工具已成功使用的话，本轮没有新的赠送操作要求。

保持原来的消息推送、定时补单、账户权限和密钥配置。3秒云端冷启动、真正丢失通知的补单和苹果实机付款仍需按原清单核验；本轮没收取真实费用，不替你确认这些云端结果。

## 校验与问题反馈

目录内每个 ZIP 都有对应 `.sha256` 文件，完整清单在 `upload-manifest.json`。Windows 可用 `Get-FileHash -Algorithm SHA256 文件路径` 与它对照。包内 `applied=false` 表示本轮未自动部署。

若自己的账号仍显示“订阅即将开放”：先核对新 `palm-api` 是否已部署，再确认手机打开的是新预览／体验版。有效会员应优先显示“已拥有”；若身份读取失败，先重试，不要反复支付。需要反馈时提供页面提示和订单号即可，不发送 AppKey、管理员 API Key 或随机口令。
