# 添加物品与发现页视觉改版 · 2026-10-08

同日按用户补充的效果图细节更新水彩猫、撕边纸纹、胶带编号与横向照片入口；当前显示与验证见 [细节补齐记录](editor-discovery-fidelity-20261008.md)。以下为初轮改版记录。

## 实施结果

- 添加／编辑页与发现页采用奶油白 `#F7F4EF`、深棕文字及顶部 60% 淡粉拼贴，内容最大宽度 480px，左右留白 18px、卡片圆角 16px。原生导航栏颜色同步，添加与编辑的标题按入口区分。
- 照片入口前置；基本信息、购买与保修、备注分别分组。保留选图、拍照、裁剪、旋转、照片失败重试和上传进度。开关关闭时显示提示并禁用选择与无效下载重试，不影响资料保存。
- 名称 120 字、分类 60 字、备注 1000 字及原日期约束保留。照片资料部分成功重试、版本冲突、账号保护和草稿流程没有重写。
- 保存使用原有 `assets/paper/save.png`：档案盒、胶带、勾选邮票与长纸片；全内容宽、随页面滚动。`paper-label` 新增默认关闭的内部 `fitWidth` 属性，仅此保存按钮启用，用于适配宽度；其他纸签布局不变。按钮保留原生点击、加载、禁用和重复提交保护。
- 发现页增强数量／净成本、支出分项、分析标签和计算依据的层级。分析物品入口改为原生按钮，使用现有分类图标。本轮不新增照片下载；分析响应没有最新照片版本时，也不按物品 ID 猜测缓存，避免旧照片误显示。
- 本月小报使用胶带纸片、月份、金额分栏及统计截止日期；整卡和标题旁入口都保留原跳转。本月陪伴空状态使用已有猫爪账本与邮戳素材；真实纪念仍按原数据渲染。
- 发现页业务脚本、接口、金额计算和三项底部导航配置未修改。本轮没有新增业务字段、远程装饰图片、云函数部署或体验版上传。

## 验证记录

### 回归与离线布局

- 相关现有回归 **66 项通过**：draft-detail、photo-unavailable、photo-submit、navigation-discovery（32 项）；frontend、photo-cache（34 项）。覆盖草稿恢复、照片选择取消及权限失败、裁剪／旋转、重复保存、资料已存而照片重试、版本与账号保护、独立部分失败重试和导航。
- 实际两页 WXML／WXSS／本地图片以合成数据渲染，共 **26 组布局通过**，宽度为 320／390／430／768px。覆盖有／无照片、关闭／加载／失败／上传、保存中、版本冲突、已处置、草稿弹窗、空发现、各部分读取失败、长标题／说明／物品名、大金额、多条纪念与不同月份。
- 测量确认无横向溢出，内容不超过 480px，所有按钮至少 44px；照片区在基本信息前，保存与内容等宽，纸纹透明度为 0.6 且不接收点击。

## 发布与待补

当前微信体验版尚未包含这轮改版，本轮没有上传、提审或发布。小米 K80 Ultra 的键盘避让、滚动、实际选图／拍照、保存和取消待真机复核；模拟器和现有单元回归不能替代手机结果。
