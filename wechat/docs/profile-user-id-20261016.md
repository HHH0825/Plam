# 个人设置中的用户ID

入口：**我的 → 个人设置 → 用户ID → 复制ID**。

沿用后端已分配的唯一账户编号，显示值与 `palm_users` 中用户记录的 `id` 字段相同。管理员今后给指定账户赠送会员时，可直接使用这个编号，无须再生成或维护另一套映射。修改昵称不会改变编号。

编号仅显示在当前登录用户自己的个人设置里，没有新增用户搜索或查询他人ID的接口。ID用于定位账户，不是密码；知道编号不能直接登录账户或获得会员权限。用户主动复制后，可以按需提供给维护者。

读取中、读取失败或缺少合法ID时，不生成临时编号；提供重新读取。切换账号会清空旧ID，并阻止旧账号信息被复制；离开页面后忽略迟到响应。复制失败提供重试提示。

- 未修改后端、会员或支付接口，未写入云端账号数据，未上传或发布正式版本。未进行实体手机剪贴板验收。
