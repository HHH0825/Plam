## 使用规则

- 心愿不默认设置考虑日期。支持编辑、确认删除、暂不买与恢复考虑。
- 保存心愿、转物品前提示最多三件本人现有物品；名称精确、名称包含、分类相同依次匹配。闲置物品参与，处置或回收站物品排除。提醒不阻止购买。
- “已购买，转为物品”使用现有表单，可修改实际购买信息。取消不会改变心愿；每条心愿只产生一个物品，照片失败继续重试原物品。转换草稿独立保存。
- 固定费用支持会员／服务、按月设备分期，关联物品可选。计划与提醒不会记账，只有“确认已付”产生实际支出。
- 服务有效期与付款日期分别提示。暂停／结束只停止本程序后续提醒，用户需自行向服务商取消真实订阅。
- 分期本金按分均摊、尾差放最后一期；可修改实际本金、利息手续费或提前偿还。若原期数结束但实际本金未还清，继续提供补还周期，直到余额为零。累计本金不可超额。
- 有任何付款历史（包括作废）的费用不能删除，应设为“已结束”；无付款历史可确认删除。恢复管理保留原付款进度，不自动补记费用。
- 更改服务周期从尚未付款的下次到期日重新排期；历史付款保留原周期和设备快照。已有还款的分期不允许改首期日期。金额、设备调整仅影响新付款，历史需单独修改。
- 设备处置、移入回收站后费用保留并提示检查续费；确认关联付款时再次提示。永久删除清除可点击关联，保留设备名称、费用与付款历史，不级联删除账本。

| 项目 | 示例金额 | 物品净成本 | 月度固定费用 | 分期本金单列 |

| 维修费 | 20.00 | +20.00 | — | — |
| 已付关联服务费 | 10.00 | +10.00 | +10.00 | — |
| 已付关联利息／手续费 | 2.00 | +2.00 | +2.00 | — |
| 已还本金 | 50.00 | 不重复计入 | 不叠加 | +50.00 |
| 处置回收 | 30.00 | −30.00 | — | — |
| 合计 | | **102.00** | **12.00** | **50.00** |

日均净成本 = 累计净成本 ÷ 原有持有天数；处置后天数停在处置日。独立未关联服务费用计入全账户统计、小报和趋势，不计入某件物品成本。实际付款日期决定月份。编辑或作废付款立即重算，不额外生成一笔支出。金额整数分存储；自然日按北京时间计算。

## 数据迁移与部署顺序

### SQLite

1. 停止本地服务，备份正在使用的数据库和照片目录。
2. 使用本轮后端启动；现有初始化自动追加表并将 `user_version` 提升到 **10**。
3. 新增 `wishlist`、`fixed_expenses`、`expense_payments` 文档表和 `workflow_receipts` 幂等回执表，保留原物品、用户、目标字段和照片。
4. 使用测试账户核验新增、转换、实际付款、更正与作废，再启用客户端新入口。不要删除已有数据库重新初始化。

### CloudBase

先备份已有后端版本和配置，创建以下空集合；保持已有业务集合相同的**仅服务端访问**权限，不开放客户端直接读写。

| 集合 | 必要索引（升序、非唯一） |
|---|---|
| `palm_wishlist` | `user_id, _id` |
| `palm_fixed_expenses` | `user_id, _id`；`user_id, item_id, _id` |
| `palm_expense_payments` | `user_id, _id`；`user_id, item_id, _id` |

保留现有计数器、请求回执、用户及照片配置。索引增量清单见 `deploy/cloudbase/purchases-20261010/resources-delta.json`，`applied:false` 表示尚未应用。

1. 核对集合与权限后更新 Python API 云函数，沿用原运行时、环境变量、私有 COS 与函数设置；本轮没有新增依赖或密钥。
2. 如实际启用 Node 桥接，再同步更新桥接包；直连模式仍需确认直连路由白名单使用本轮代码。
3. 以隔离测试账户验证事务、权限、成本和清理，再上传客户端候选包。旧客户端调用目标写入会收到更新提示。
4. 最终上传前使用微信开发者工具核验**编译包体**、隐私指引和真机；本地源文件合计不是最终上传包大小。

CloudBase 永久删除先标记物品不可用，再由已有有界维护逐批解绑费用和付款记录，最后删除父物品。每次解绑读取最新记录并事务更新，保留名称快照；无需为本轮新功能另建自动扣费或提醒云函数。维护未部署或未执行时，已标记删除的设备链接也不可访问，账本仍保留。可复用原维护入口；本轮不配置定时器。

后端离线包：`deploy/cloudbase/purchases-20261010/palm-api-python310.zip`；可选桥接：同目录 `palm-api-bridge-node20.zip`。各包附 SHA-256 与源文件清单。仅打包运行代码和已有锁定依赖，不含凭证、数据库、照片或真实用户数据。复现命令：`python wechat/tools/prepare-purchases-release.py`。如之后修改后端，重新生成并核对清单后再部署。

回退前端可隐藏入口；回退后端应先确认期间新增账本不会丢失，保留新集合与数据库备份，不能通过删表回退。新账本会影响成本计算，前后端版本须一起安排。
