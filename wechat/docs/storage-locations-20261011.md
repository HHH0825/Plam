# 收纳位置管理与筛选排序 · 2026-10-11

本次交付为本地可审阅版本。**未部署云函数、未创建云端集合、未上传体验版。测试没有写入真实账户。** 上一轮订阅后端不包含本轮位置接口，正式使用位置功能前需要同步下列材料。

## 页面与操作

- 物品页第一排为“想买清单 → 订阅/分期 → 收纳位置”。三个入口带原创图标，390px 及以上普通字号同排；320px 和大字体允许换行。
- 第二排左边显示结果数量，右边是滑杆筛选与上下排序胶囊。无下三角；筛选生效使用黄色与条件数量，排序继续使用原生选择器。
- 收纳位置采用单层清单：搜索、新增、未设置位置和自建位置数量；每件物品最多一个位置。位置名称 1–40 字，首尾去空白，重复时提示使用已有位置。
- 点击位置查看物品，支持改名、确认删除、添加物品、多选移动及清除。添加时标注“已在这里”；搜索保留选择，单批最多 50 件。移动前确认目标与件数，冲突后保留勾选，必须刷新核对后再确认。
- 原详情页身份区下方增加可点击位置行和单件更换；新增/编辑物品及心愿转换表单增加可选位置。物品首页卡片不增加位置行，仍突出相伴天数与日均花费。
- 新图标是猫耳收纳盒与粉色标签。SVG 源文件和透明 PNG 位于 `miniprogram/assets/purchase-entry/`；同时增加滑杆与排序图标。5 枚入口/控件 PNG 总共 7346 字节，SVG 继续不进入运行包。
- 微信原生默认按钮宽度会影响新页面。样式已明确覆盖其默认宽度，使位置行与物品行铺满内容区、新增与文字按钮保持紧凑。批量栏位于安全区域上方，目标弹层位于它上方。

## 数据与兼容

- SQLite `user_version` 升至 **11**。新增 `storage_locations` 文档表；`items` 增加可空 `storage_location_id` 和默认 0 的 `revision`，增加位置检索索引。
- 旧 SQLite 数据库升级前自动生成同目录 `<数据库名>.pre-locations.bak`，创建表/列/索引在同一初始化事务中执行。现有物品默认为未设置，不读取备注推断位置。
- CloudBase 新集合为 `palm_storage_locations`。账户归属由后端校验，客户端不直读数据库。每次请求缓存位置映射，避免逐物品查询位置。
- 位置逻辑删除，原物品行不级联删除；所有物品读响应把删除的位置解析为 null。回收站物品不计数，恢复时保留仍有效关联；已处置物品不计数、不再分配，但仍可查看最后有效位置。
- 旧客户端编辑遗漏位置键保留原位置。明确提交 null 才清除。位置接口失败时编辑器禁用更换并省略该键，其他物品资料仍可保存；失败不伪装成成功空清单。
- 批量分配先验证整批，再在一个事务内写入物品和请求回执。稳定请求编号可重放已成功结果；版本冲突和跨账户请求整批回滚，禁止覆盖旧版本。CloudBase 暂时提交失败也通过回滚/同编号重试验证。
- 本轮不改变购买价格、维修、订阅、处置、持有天数或日均计算规则。

完整字段和请求格式见 [接口说明](api.md)。

## 后端部署材料与手动同步顺序

目录：`deploy/cloudbase/storage-locations-20261011/`。所有清单仍为 `applied:false`。

| 文件 | 用途 |
|---|---|
| `palm-api-python310.zip` | 完整 Python API 候选包，含收纳位置与现有订阅/照片等功能 |
| `palm-api-bridge-node20.zip` | 桥接路由白名单更新；启用桥接时同步 |
| `resources-delta.json` | 新集合、权限及新增索引清单 |
| `manifest.json` / `*.zip.sha256` | 源码、依赖基线及压缩包校验值 |

1. 备份现有函数代码、配置和数据库，确认环境为 `cloud1-example`。保留现有凭证、会话、私有 COS 与照片配置。
2. 在文档数据库创建 **`palm_storage_locations`**，权限选 **无权限 `[ADMINONLY]`**，即仅服务端管理员访问。不要选择所有用户可读写。
3. 新集合建立普通组合索引：索引名可填 `user_id_1_id_1`；字段按顺序为 **`user_id` 升序、`_id` 升序**。不勾选唯一，不勾选稀疏，部分过滤条件留空。索引名只是名称，字段需要逐项添加。
4. 在已有 **`palm_items`** 集合补普通组合索引：可命名 `user_id_1_storage_location_id_1_id_1`；字段依次为 **`user_id`、`storage_location_id`、`_id`，全部升序**。同样非唯一、非稀疏、无过滤条件；不修改已有集合权限。
5. 等索引可用后，用本轮 `palm-api-python310.zip` 更新现有 `palm-api`，继续使用现有 Python3.10 启动配置。若使用桥接，再同步本轮桥接 ZIP。**创建集合本身不会启用新接口，必须同时更新后端。**
6. 在隔离测试账户核对位置读取、新增、批量移动、重复请求、冲突及账户隔离，再同步客户端。旧物品不需要逐条补写位置字段。

应先创建集合再更新 API：新 API 的物品响应会解析位置，缺少集合会影响读取。新增索引仅建结构，无需手工填入用户文档或修改已有物品。发布后如需回滚，保留新集合/字段及其数据，使用备份代码和客户端；SQLite 按升级前备份恢复时先另存升级后的数据。

打包使用本地固定的 Python Linux 与 Node 依赖基线，检查 ZIP 完整性、启动脚本 LF 与执行权限、Python 源码可编译及源码哈希；未下载新依赖，未包含账户数据库、照片或密钥。可通过 `tools/prepare-storage-release.py` 重建。
