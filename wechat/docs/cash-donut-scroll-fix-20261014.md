# 圆环遮挡导航与滚动漂移修复 · 2026-10-14

## 交付状态

**修复已落地，本地回归通过，微信原生滚动效果待验。** 本轮未使用Computer Use，未部署、上传体验版或修改后端。

原实现将可见Canvas放在圆环位置，截图显示它盖过普通固定导航，并在滚动中出现相对位移。此次移除页面中的可见圆环Canvas，改为屏幕外绘制透明PNG、使用普通图片展示。导航层级及玻璃样式未修改。

## 实现

- 共享组件继续接受`rows／amount／size／plain`，颜色、比例、尺寸及中心真实金额保留。Canvas固定在屏幕外，仅用于生成，不参与可见图表展示。
- 按设备像素比生成完整透明PNG，避免导出时只截取画布左上部分；普通模式与小报纯圆环模式沿用现有绘制几何参数。
- 滚动不绘制、不导出；分类展开和金额遮罩不改变圆环数据时不重新生成。
- 绘制及导出串行执行，连续更新合并为最新任务。过期任务及旧账户的结果丢弃；替换、图片失败、组件销毁时释放组件生成的临时文件。
- 生成中显示中性占位，失败显示“图表暂不可用”，真实金额和分类列表继续显示。统计页重新读取完成后显式通知组件检查重试，同样的数据也可恢复失败图表；正常图表根据相同签名跳过重复生成。
- 小报预览改用共享组件的`plain`模式，移除原页面直接绘制的圆环Canvas；小报导出流程及金额隐藏规则不变。
