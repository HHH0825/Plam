“我的”账户概览下新增“猫爪会员”，带“会员订阅”标签。订阅页默认选中年会员，价格为3.9元／月、9.9元／季、29.9元／年；三个套餐权益相同，到期手动续费。“订阅即将开放”为禁用按钮，不存在购买成功或公开测试开通流程。

## 账务与到期规则

- 一笔流水仅属于一个账本；退款继承原支出的账本和标签。来源流水更新不覆盖独立保存的整理结果。
- 老流水与旧客户端未指定账本的新增请求默认属于日常账本。全部账本汇总一次，归档账本仍参与总计；有流水（含作废记录）或未来付款引用的账本不能删除。
- 自定义分析与预算使用实际收付日期；预计账单不会计入实际收支。退款在实际退款月抵减，收入不抵减预算消耗，分类预算不与总预算相加。
- 批量付款由客户端逐项提交，每项使用既有付款事务与稳定重试编号。付款、计划进度与关联流水在同项事务内完成，成功项不再重试。
- 权限由后端检查，写入提交前再次检查到期；事务中到期回滚。已成功请求的原编号重试可在到期后返回原收据，不会产生新付款。
- 到期保留账本、标签、预算和分析方案。已有流水继续免费查看、修改、退款和作废；新增流水默认进入日常账本，已有计划可走免费单笔付款。
- 到期回到默认外观，保留装扮选择，续费恢复；已导出的图片不受影响。服务失败提供重试，不把未知权限当作到期，不删除配置；已知到期时间仍会使装扮回到默认。
- 权限缓存和异步请求绑定账户，退出、切换账户、重新进入页面及到期刷新。旧账户响应不能更新当前页面。

## 本地测试会员

先按项目开发说明启动本地 SQLite 服务、完成本地模拟登录，再在已激活 Python 环境的终端中执行（以下相对路径以项目根目录为准）：

```powershell
$env:PALM_WECHAT_DEV_LOGIN = '1'
$env:PALM_STORAGE_BACKEND = 'sqlite'
python wechat/tools/grant-test-membership.py --database wechat/instance/palm.sqlite3 --user-id 1 --status active --months 12
```

实际数据库路径和用户ID以本地服务为准。状态可用 `active`、`expired`、`expiring`，最后一种在约两分钟后到期。工具只操作显式指定的本地数据库，拒绝 CloudBase 和非开发模式；后端没有公开开通接口。测试月份只用于生成测试有效期，不构成真实计费规则。

建议依次核对免费账户、有效会员、已到期会员、操作途中到期、断网重试、切换账户以及旧后端返回404的场景。免费账户可看权益说明与带示例标识的装扮预览，会员操作会进入会员页。

## 接口与数据

| 路径（统一前缀 `/api/mp`） | 方法 | 用途 |
| --- | --- | --- |
| `/membership` | GET | 套餐、状态、开始与到期时间、权益、关闭的支付状态、资源目录与外观 |
| `/member/books`、`/member/books/<id>` | GET／POST、PUT／DELETE | 账本管理 |
| `/member/entries`、`/member/entries/move` | GET、POST | 分页流水与批量调整归属 |
| `/member/tags`、`/member/tags/<id>` | GET／POST、PUT | 标签创建和改名 |
| `/member/entries/<id>/tags` | PUT | 添加或移除流水标签 |
| `/member/analysis/run` | POST | 自定义分析、对比与分页明细 |
| `/member/analysis-presets`、`/member/analysis-presets/<id>` | GET／POST、DELETE | 保存、读取与删除常用方案 |
| `/member/budget` | GET／PUT | 月度／分类预算 |
| `/member/bills`、`/member/bills/<plan-id>/confirm` | GET、POST | 月历及每项独立确认 |
| `/member/plans/<id>/book` | GET／PUT | 后续付款账本 |
| `/member/appearance` | GET／PUT | 保留的选择与当前有效外观 |

现有流水列表和统计支持可选 `book_id`；不传保持全账户口径。金额保存整数分，业务日期沿用北京时间。写操作沿用版本检查、请求编号及事务；付费动作额外检查服务端会员状态。

SQLite新增 `member_documents` 表，包含账户、类型和JSON载荷，版本升至14；CloudBase新增 `palm_member_documents` 集合，类型为会员状态、账本、流水元数据、标签、预算、方案、装扮、计划路由。文档ID由账户、类型和业务ID生成，读取仍检查账户。
