# 会员图标、工具入口与身份卡片验收

本次仅修改前端资源、展示和导航。未修改支付逻辑、后端接口或会员权限，未部署正式环境，未发起真实支付。

## 已实现

- 四幅权益图标依据原图重新绘制，再压缩为透明 PNG；订阅页显示尺寸保持不变。“我的”新入口复用同一资源，高清源图仅放在本文的验收目录中。
- “我的”会员卡下、“我的收藏册”上增加五行：我的账本、账单日历、自定义分析、月度预算、会员装扮。免费用户可进入现有预览页，付费操作仍经过原有权限校验。
- 未开通保留淡黄票券卡；已开通使用暖金渐变、猫咪抱票券插画、“已开通”、北京时间到期日期及“管理会员”；到期恢复淡黄卡并显示“已到期”“续费会员”。卡片始终打开原会员订阅页。
- 状态读取中、失败及后端未开放分别显示中性提示；失败提供重试。切换账号先清除旧身份，成功开通返回页面及跨过到期时间后重新读取。

## 尚未覆盖

模拟器的自动点击连接持续超时，因此原生截图通过离线副本直接打开目标页取得，不能作为实际点击成功的证据；跳转行为由前端交互测试覆盖。未进行实体手机上的视觉、字体设置和真实支付验收。

在开发者工具重新编译并生成新预览后，可用手机确认“我的”五行入口与会员卡。真实会员身份始终取决于后端返回的状态，截图中的已开通账号仅是隔离测试数据。
