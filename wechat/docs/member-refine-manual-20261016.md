# 会员工具精简与页面更新：中文操作说明

本次更新目录：`wechat/deploy/cloudbase/membership-refine-20261016/`。这是新的独立更新包，不要与上一份 `membership-polish-20261016` 混用。本轮只做本地开发和隔离验收，没有修改真实会员、账目、支付开关或云端配置，也没有发起付款。

## 本次变化

1. “我的”会员工具变为4项：我的账本、自定义分析、月度预算、手账外观。右侧使用浅黄色圆形加减号，展开／收起仍按账号记忆。
2. 会员账单日历和批量确认已删除；免费的“订阅／分期”、单笔确认已付、统计页的收支日历及历史记录继续使用。旧会员日历链接会提示已下线。
3. 我的账本按已确认草图改为“账本／流水整理／标签”分栏。账本列表上方不再有两个跳转按钮；新建、编辑在底部表单完成，归档账本独立收起。自建账本右侧“•••”打开编辑、归档／恢复及符合原条件的删除操作；默认账本沿用原保护规则。
4. 月度预算突出剩余额度、总预算和已用金额，分类额度在下方。设置预算进入底部表单；“沿用上月额度”只填入草稿，必须点“保存预算”才写入。关闭未保存的预算会询问是否放弃。
5. 会员页保留当前插画、套餐卡、配色和购买区，只增加首项免广告权益、说明收放和免费／会员对比入口，移除底部服务说明按钮。
6. 免费／会员对比页先说明免费版足够日常使用，左列列免费功能，右列在相同功能下面增加会员权益。原购买和退款说明在该页底部“购买与服务约定”中。

免广告目前是预留权益：**当前没有投放广告，本次也没有接入广告**。有效会员返回 `ad_free` 权益，未来接入广告时仍需以服务端身份执行免广告判断。

## 一、更新后端 palm-api

1. 先保留当前云函数版本、环境变量和自己的源码备份。
2. 腾讯云 CloudBase → 云函数／托管 → 函数管理 → **palm-api** → 函数代码。
3. 沿用上次的ZIP上传方式，上传本次目录中的 **`palm-api-membership-refine-python310.zip`**。
4. 保留现有运行环境、执行入口、网络配置及全部环境变量实际值，再保存／部署代码。
5. 本次**不需要增加或删除数据库集合、索引或字段**。不要清空会员文档，也不要删除历史计划付款记录。

包内 `palm-api-env.example.json` 仅供参考，不能整份覆盖你的云端配置。AppKey、管理员 API Key、通知口令等沿用你原来的值，不需要重新生成或发送到聊天。

本轮后端变化是移除会员日历专用接口，以及更新会员权益目录；购买价格、已拥有限制、赠送和付款授权计算、退款和补单逻辑均沿用现有版本。

## 二、更新小程序前端

如果开发者工具打开的就是本项目的 `wechat/miniprogram`，代码已更新，直接重新编译。如果使用另一份项目：

2. 确认是原来的猫爪物帐 AppID、云环境和已经验证的本地私有配置。包内不含你的 `project.private.config.json`。
3. 重新生成手机预览或体验版，重新扫码体验；旧预览包不会自动更新。
4. 按下面清单确认后，再由你上传、提审和发布。

建议先更新后端，再体验新前端。旧前端中的会员日历在新后端上会不可用，因此两部分应配套更新；免费的订阅／分期不受影响。

## 三、你在手机上这样核对

- “我的”：会员工具显示4项，加号展开、减号收起，返回页面会记住选择；另一个账号独立记忆。
- 我的账本：默认进入账本列表。点击“＋新建账本”看到底部表单；自建账本右侧菜单可以编辑或归档；归档区域可以展开并恢复。流水整理和标签分栏仍可操作，关联退款跟随原支出。
- 月度预算：切换月份／账本，核对金额与统计一致。点击沿用上月额度，只应打开带草稿的表单；没有保存时，当前已生效的预算不应变化。编辑、保存后再返回核对。
- 会员页：整体仍是现有风格，第一项是免小程序内广告且不能点开。初创说明默认展开，点击标题行可以收起；下方可以进入免费版与会员对比页。
- 对比页：免费功能两列相同，右列再有额外权益。页面底部的购买与服务约定可展开，显示当前设备目录及退款说明；返回会员页不会发起付款。
- 免费版／已到期账号：可以查看账本及预算的已有内容、对比说明，编辑写入仍需要有效会员。有效付费会员和赠送会员仍显示“已拥有”，不能重复购买。
- 订阅／分期：仍可查看计划及历史付款，并按原流程单笔确认实际付过的钱。统计里的日常收支日历仍存在。

原先已经保存的订阅付款账本映射继续兼容。带历史流水或仍有关联计划的账本不能直接删除，可归档保留；不会为了删除会员日历而重分配旧记录。
