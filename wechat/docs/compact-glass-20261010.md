# 白底紧凑布局与玻璃导航验证记录

日期：2026-10-10。修改仅在本地；未部署云函数、未上传体验版、未修改审核或发布状态。

## 已完成

- 底部导航改为左右留白18px、最大444px、高64px的悬浮胶囊；底部留出安全区域与10px间距。乳白半透明底、18px背景模糊、边缘高光和柔和阴影均由样式实现，没有持续绘制循环。模糊被忽略时仍保留90%不透明度白底。
- 中央64px黄色新增按钮移除十字；使用独立紧裁切猫爪，实际显示宽32px。现有添加、登录校验、防重复跳转和返回位置逻辑不变。
- 普通物品卡片最小108px、间距8px，左侧72px缩略图，右侧集中显示名称、分类/状态、陪伴天数和净成本/天。详细金额与日期在详情查看；照片墙与已有布局偏好保留。
- 我的标题区88px、资料卡76px；小小发现并入我的收藏册。五个菜单改为56px单行，保留回收站30天提示；退出按钮48px。昵称、头像和微信原生反馈沿用原逻辑。
- 详情使用112px照片或分类图，照片按完整比例展示；每日净成本28px、陪伴天数20px、累计净成本底部横行。购买价/天移到基本资料展开区。纪念采用小猫爪与日期，不再使用大邮戳与胶带。
- 图标沿用原创SVG，额外制作紧裁切版本，系统字体不变。没有引入第三方界面库或苹果字体/图标。

该玻璃是适合微信WebView的视觉近似，不包含苹果原生材质的实时折射、动态明暗适配。正文保持白底。参考：[网页液态玻璃文章](https://juejin.cn/post/7514618352829448244)、[Apple Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。

| 玻璃回退 | 本地强制关闭两种backdrop-filter，布局与点击区域保持完整。截图明确为浏览器渲染，不冒充微信或真机证据 |
| 原生导航流程 | 使用现有组件方法完成我的→物品→我的；我的重复新增仅一层添加页；返回后小小发现点击可进入二级页，返回我的选中值仍为1 |
| 账户与云端 | 无新增、编辑、删除或上传测试物品/照片/记录；没有修改账户资料 |

实际取证过程中，开发者工具自动化曾出现跨组件查询超时、切页瞬间页面栈丢失和空白截图。这些结果未作为通过证据；模板与样式编译检查通过，重新编译后改用现有组件导航方法、菜单点击与稳定页面截图完成验证。`native-`截图均需人工查看后才列入下表。

## 筛选导航遮挡修复（2026-10-10）

- 原因：筛选使用 `wx.hideTabBar/showTabBar`，未隐藏新的自定义导航。先前本地层级比较无法验证微信自定义导航宿主，遗漏了实际遮挡。
- 修复：筛选打开时从视图中移除自定义导航；确认、关闭、页面隐藏/卸载后恢复。组件显示时根据当前页面筛选状态同步，隐藏期间拒绝新增和切换导航操作。保留原生导航兼容调用。
- 相关17项回归通过，涵盖重置不关闭面板、确认/取消恢复、页面隐藏/卸载、账号变化以及隐藏期间拒绝导航。没有发送写入请求。
- 物品页28个本地排版场景通过（320/390/430/768px），筛选检查改为导航缺席、两按钮位于可视范围内且中心可命中。
- 微信模拟器实际点击重置、查看结果、关闭按钮与遮罩均成功。重置后面板保持开启且导航隐藏；确认后面板关闭且导航恢复。两操作按钮实测均高48px。
- 实际截图：[筛选修复](images/compact-glass/native-filter-fixed.jpg)、[关闭后恢复](images/compact-glass/native-filter-restored.jpg)。
- 真机待补；仅本地修改，未上传体验版、未部署云函数。
