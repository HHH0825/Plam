# 物品详情页视觉改版 · 2026-10-08

## 实施结果

- 详情页使用奶油白背景、深棕文字、16px 圆角和顶部 60% 纸纹；最大内容宽度 480px，手机左右留白 18px。原生导航栏背景同步为奶油白，没有新增底部导航。
- 真实照片使用 200px 高的宽幅区域、等比填充，档案编号放在照片下方。竖图会裁切上下部分，这是宽幅等比填充的结果；原文件未改动。无照片时保留 64px 分类插画。
- 名称 26px，状态紧邻名称；分类、购入日期及价格为次要信息。第一行优先展示陪伴天数和净成本／天（28px），第二行保留购买价／天和累计净成本（20px）。已处置物品显示“曾持有”，没有改账目计算。
- 编辑物品为绿色白字主按钮，更多操作为浅色描边按钮，保留忙碌时的禁用逻辑。
- 纪念使用现有名称、日期和下一次纪念数据，加入本地猫爪、胶带与邮戳装饰；不硬编码示例纪念。目标、资料折叠及历史使用记录仍沿用现有逻辑。
- 维修与处置集中到同一张卡片；空状态复用猫爪账本标志，处置按钮使用档案图标。保留记录编辑、展开和已处置限制。
- 只修改详情模板、样式、导航栏颜色并新增本地素材，详情业务脚本、客户端配置及后端没有在本轮修改。所有新增素材均为项目内矢量图及三倍 PNG。
