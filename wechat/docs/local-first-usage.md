# 猫爪物账 2.0.0：本地使用与完整备份

更新日期：2026-11-11。2.0.0 已正式上线，免费、免登录，业务资料保存在当前手机。无需自行开通微信云开发、云服务器或部署后端。

## 开始记录

微信搜一搜搜索「猫爪物账」。首次下载和尚未下载的页面分包需要网络；相关代码包已下载后，物品、照片、记账、统计和小报等核心功能可本地运行。微信聊天文件分享和重新选择文件仍依赖微信及设备实际能力。

物品、维修、处置、回收站、收纳、想买清单、收支、退款、账本、预算、订阅／分期和小报均免费。昵称、预设头像和外观是本机设置。没有会员购买、容量兑换、邀请奖励或趣味签到，不设商业性数量限制；设备空间和微信文件限制仍然适用。

## 数据存在哪里

资料和持久照片在当前设备的微信小程序文件目录，普通缓存只用于少量设置和索引。不会自动上传到开发者业务服务器，不提供跨设备自动同步，也不与 PALM 网页版共享资料。

换手机、卸载、清理小程序数据、设备损坏或丢失都可能使资料无法恢复。开发者没有云端副本，无法代替用户找回未备份资料。内部恢复版本用于异常恢复，不是手机之外的备份。

## 导出后发送到聊天

1. 打开「我的」，点击底部横向「资料与完整备份」状态栏。
2. 点击「生成完整备份」。文件生成成功后，点击发送／分享按钮打开微信文件分享面板。
3. 选择接收方，可按设备实际支持选择文件传输助手、自己的聊天或可信联系人。也可进一步保存到电脑等可靠位置。
4. 核实文件已发送或保存，并能重新选择，再回到小程序点击「确认已保存到外部」。仅生成 ZIP 或取消分享不算已备份。

ZIP 包含资料、历史、回收站、设置和照片，默认不加密；接收者能够读取内容，请妥善保管，不要公开上传。生成文件必须先在小程序内临时写入；确认外部保存后清理对应临时 ZIP。未确认的导出正常只保留最新一份，下一份成功生成后替换旧临时包，生成失败保留上一份。

「本机空间 → 清理临时备份包」可以清理导出 ZIP 及打包临时资料，不删除原始物品、账目、照片、聊天文件或内部恢复版本。清理失败可重试。备份日期只是保存确认记录，不代表外部文件永远存在，仍需自己保管。

## 从聊天恢复或转移到另一台手机

1. 在新手机打开同一小程序，进入「资料与完整备份」。
2. 选择「选择聊天中的 ZIP 备份」，从微信聊天中选择本应用生成的 ZIP。
3. 核对备份日期、资料数量与照片数量。文件会先进行格式、校验和关联关系检查。
4. 当前设备已有资料时，先生成并保存当前完整备份，再明确确认整库替换。
5. 完成后检查物品、照片、账目与统计；失败时保留原资料，不自动清空。

恢复采用整库替换，**不会合并两台设备的记录**。仅支持本应用生成的备份格式，不支持任意 ZIP、加密 ZIP 或更新版本的未知格式。不要删除唯一一份可用外部备份。

## 旧云端用户

由于使用人数较少，项目停止提供原云端存储，2.0.0 直接改为完全免费的本地工具，没有发布自动迁移过渡版。旧云端物品、账目和照片不会自动出现在新版，也不会自动下载到手机。对此造成的不便，我们深感抱歉，感谢理解。

已有本机资料及本应用的完整备份可以继续使用。历史云端代码留在仓库供查阅，不代表旧服务仍可访问。云资源关闭不会替代手机备份。

## 故障与反馈

空间不足或写入失败时，先保留当前资料，按提示清理临时文件或导出备份。资料损坏时使用界面提供的内部恢复候选或导入外部备份，不通过清空资料来排除故障。

通过 [GitHub Issues](https://github.com/HHH0825/Plam/issues) 提供版本、设备、步骤与错误信息，遮挡个人资料和账目；不要附上完整个人备份。安卓／苹果实际文件流程可能随微信和系统版本而不同，模拟器检查不能保证所有设备行为一致。
