## 上传步骤

在 PowerShell 中执行，先暂存且检查范围：

```powershell
Set-Location '.'
git add -A -- wechat
git diff --cached --check
git diff --cached --stat
git diff --cached --name-only
```

检查输出的文件路径应全部以 `wechat/` 开头。不要使用 `git add .`，否则可能把当前桌面版／网页版的其他改动一起加入。`-A -- wechat` 会同时记录这个目录中的新增、修改和旧文件删除；旧素材与组件的删除属于当前源码状态，不能只上传新增文件而留下已淘汰文件。

确认范围和差异后执行：

```powershell
git commit --only -m "更新微信小程序至1.1.0" -- wechat
git push origin main
```

`--only -- wechat` 将本次提交限制在这个目录，仓库其他目录的本机改动保留。若前面的检查报告空白行或其他差异问题，先核对后再提交；不要在错误后继续机械执行后续步骤。

推送完成后，打开 GitHub 仓库的 `wechat/`，查看最新提交和顶部 README。开发者工具应导入该目录下的 `miniprogram/`。这是提交源码，不会自动上传微信、提审发布或部署后端。

如果提示 SSH `Permission denied (publickey)`，需配置此电脑对该 GitHub 账号的 SSH 访问；不要把令牌写进源码。如果提示远程有新提交或 `non-fast-forward`，停止推送并核对双方变更，不使用强制推送，也不要在当前仍有其他改动时直接重置或覆盖整个仓库。
