# 打开即进入物品页：自动连接与关于猫爪

本轮仅修改本地客户端，没有部署云函数、修改正式业务数据、上传体验版或发生真实付款。

## 本轮变化

- 普通启动始终进入“我的物品”。首次使用和会话过期时自动识别当前微信对应的账户；有效会话直接复用。
- 身份准备期间显示物品页骨架及“正在打开你的物品…”，不加载旧账户私有内容，也不把连接失败显示为空列表。
- 失败留在当前页，明确提示并提供重试。失败后不会因反复显示页面而无限重新登录。
- 同时出现多个401时合并恢复；读取最多自动补读一次，仍失败则等待手动重试。保存、删除、付款不自动重发，保留填写及原提交编号。
- 同账户更新连接凭证时保留页面归属、表单、照片及待确认订单；不同账户先清屏、释放旧页面，再重新进入物品页。
- 个人资料的未保存填写使用按环境／账户隔离的临时内存快照；同账户恢复和返回后可继续填写，不写入云端。预算编辑也避免后台返回时被自动读取覆盖。
- “我的”移除退出登录按钮，在设置菜单增加“关于猫爪”；个人设置底部增加“重新连接微信”，有未保存资料时先确认是否放弃。
- 原插画页面改为 `/pages/login/about`，保留示例数据，按钮改成“开始记录”。旧登录地址仍能进入物品页；两类小报的通用分享入口同步改为物品页。
- 个人设置转入独立分包，页面地址仍为 `/pages/profile/index`；保留主包原有1450000字节保守上限，不扩大体积门槛。

## 你需要操作什么

1. **使用正式目录** `wechat/miniprogram`，或将本轮 `catpaw-miniprogram.zip` 解压到独立目录导入微信开发者工具。不要上传 `test-results/auto-session-native-project`，那是屏蔽网络、使用模拟账户的离线验收副本。
2. 预览／上传体验版，用自己的微信检查首次进入、已有物品、前后台返回、保存及资料重新连接。关于页进入后应能正常返回，底部五入口导航保持正常。
3. 使用独立的测试微信核对账户隔离；在自己的手机上断网后重新打开，确认失败重试可用，恢复网络后回到原账户。不要为测试删除正式物品或支付订单。
4. 体验检查通过后，上传客户端、提交审核并发布。本轮没有新接口、数据库迁移或后端部署步骤。

之前“两项工具免费＋2.9元月会员”的后端若尚未更新，仍按[上一轮说明](free-tools-20261025.md)单独完成；本次自动连接本身复用现有登录接口。

## 会话及接口说明

服务端仍使用现有 `/auth/login`、`/auth/me`、`/auth/logout`，微信身份与用户ID绑定和7天有效期均不变。没有新增手机号、微信头像或微信昵称授权。

`app.ensureSession()` 合并连接请求；`recoverSession(owner, credential)` 只恢复发起请求的账户，已更新凭证的迟到401不会再次开一轮登录。`reconnect()` 撤销旧会话并建立新会话，成功后回到物品页；撤销失败时仍保留原订单核对和账户隔离。

内部 `globalData.token` 是当前运行期间稳定的页面归属标识，`globalData.accessToken` 是实际服务端凭证。所有HTTP、云函数及本地照片传输从统一接口读取后者，不能把页面归属标识自行写入新请求头。同账户刷新不使正在等待的展示请求失效，不同账户会清除缓存。持久化的 `palmSession.token` 仍保存真实有效凭证，兼容旧版存储和客户端回退。

重连不等于切换微信账号，也不会删除物品、账目、会员或订单。未确认写入继续使用原有账户隔离的请求记录；不会把旧账户草稿带入新账户。
