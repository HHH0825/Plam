- 文件持久化、分片表、串行跨表事务、两代描述符、校验和保存回执；损坏或读取失败不初始化为空。资料与控制目录均有保留证据的显式恢复路径。

- 免费免登录，本机昵称／头像／外观；移除趣味签到入口与打卡操作，保留日常问候。历史签到仅作为兼容资料保留，不再新增。会员／权益／喵铺原地址兼容落地，移除购买、兑换和邀请参数。

- 迁移账户绑定快照、分页／照片续传、云端变更复核、候选持久化、外部备份、原子确认与旧客户端写入保护。确认回执丢失先查状态，激活失败可重试，云端原资料保留。

## 已知限制与待验收

1. 安卓／苹果真机文件分享、外部保存、重新选择、整库恢复和实际好友分享未测试。云端迁移方案已取消，不作为当前验收项。
2. 能显示已用空间，不能可靠保证获取微信剩余空间或在所有设备预检足够容量。写入失败保留旧资料，不清空记录腾空间。
3. 主物品列表已分页；复杂账目、统计和完整恢复仍可能持有较多结构化资料，超大数据需继续压力测试。
4. ZIP仅支持本应用未加密的存储格式，不支持密码、ZIP64或任意第三方压缩包。单文件16MiB、容器1GiB、60000项为防护上限，不是设备可用容量承诺。
5. 安全清理保护两代资料与恢复证据，不自动删除历史数据目录、导出备份或全部过期云快照照片副本。云资源清理与关闭由用户另定。
6. 未测完整首次下载、缓存启动及真机耗时对照，不承诺提速比例。断网以代码包已下载为前提。
