# 升序排序、收纳按钮与剩余时间进度条

## 已实现

- 物品与已处置档案末尾增加日均净成本升序；胶囊显示“净成本/天 ↑”。保留置顶优先、空值最后及同值编号降序，旧排序编号不变。两个页面独立保存偏好。
- 收纳位置“更换”按钮距卡片右侧12px，点击范围至少44×44px；显式覆盖微信原生按钮宽度，长位置名称在左侧换行。位置行仍位于基本资料下方。
- 订阅列表和详情共用 `expense-progress` 组件。服务有效期显示剩余天数与淡黄猫爪进度；付款日期单独提示。分期显示距下期付款的时间进度，不把还款本金或费用比例当作时间。
- 服务填充为剩余天数÷起止日期间天数，限定0–100%。1–6天变粉色；到期当天和过期归零。尚未生效时显示生效倒计时并保持满格。仅有到期日期不估算比例；缺少到期日期提示补充。起止同日不做除零运算。
- 分期根据原始首期日期和下一期编号推算上一期日期；首期以前一个月为起点，目标月份缺少原始日时取月末。提前付款后下一周期比例可封顶100%；已还清不显示轨道。
- 暂停、结束使用灰色并明确管理状态，服务时间照常流逝。进度本身不接受点击、没有动画；猫爪素材失败时保留时间、轨道和日期。
- 北京时间自然日计算，页面显示期间跨午夜重新计算展示；隐藏、卸载及账号切换清理计时器。跨日刷新不触碰正在填写的金额或付款表单，不产生请求或支出。

- 客户端62项通过：日均净成本升序、第五项原生选择器处理、偏好兼容、服务日期缺失／未来／同日／过期、分期月末／闰年／提前付款、暂停／结束、跨午夜计时器与账号隔离，以及现有付款、续费、编辑、作废、冲突、草稿、详情、收纳流程回归。
- 离线布局40组通过：320、390、430、768px，每种宽度检查普通与1.3倍文字，覆盖订阅列表／详情、长收纳位置、物品升序及处置档案。检查无整页横向溢出、按钮右侧12px及44px点击范围、10px轨道、猫爪不越界和素材可用。离线页面为生产WXML/WXSS与共享组件展开后的布局证据，不能替代微信运行结果。
- 静态包检查：新增组件与猫爪素材引用有效，未新增运行图片。按当前排除规则估算运行文件原始合计1,001,501B；不是微信上传后的压缩包体。
- 微信模拟器22项检查通过：新增升序与空值顺序、收纳按钮12px右侧间距及44px点击范围、长名称与位置入口、服务各日期状态、实际组件数量与10px轨道、付款／编辑入口、筛选和已处置升序。使用隔离账户与内存响应，实际写入请求为零；完成后恢复原账户和请求方法。具体结果见同目录 `images/subscription-progress-20261012/native-results.json`。
- 真机iOS／Android、系统大字体、设备时间异常及跨午夜长时间前台运行未实测；跨午夜和账号隔离通过可控计时器测试验证。没有部署或自动执行真实付款。

## 接口与交付

仅新增客户端展示数据与共享组件。现有 `/fixed-expenses` 日期、付款排期、成本字段以及 `/items` 日均费用字段保持原样；未新增接口、集合、索引或迁移，无需更新后端。

本地可审阅版本；未部署云函数、未创建云端集合、未上传体验版。本次进度条不代表自动扣费、取消订阅或付款确认。
