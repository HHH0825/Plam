2026-11-06上传的2.0.0开发版微信实际主包为1,392,606字节，这是当时平台处理后的上传记录，不作为本次重新构建的体积。当前发布状态依据作者上线确认；历史上传回执留在本机，不上传GitHub。

## 交付与构建

历史本机交付目录：`wechat/deploy/local-direct-20261106/`，包含生成包与验收证据，已排除在Git之外。干净克隆不需要这些文件，按下方源码构建即可。

| 文件 | 用途 |
|---|---|
| catpaw-local-miniprogram.zip | 纯本地压缩项目，供上传及体验 |
| catpaw-local-editable.zip | 完整可编辑的纯本地项目 |
| catpaw-local-first-source.zip | 开发源码与测试备份；包含历史云端实现供留档，不是需要部署的后端 |
| release-manifest.json、SHA256SUMS.txt | 发布方式、验证结果、包体及校验值 |
| upload-result-20261106.json | 上传成功后保存的开发版回执及绑定ZIP校验值 |

项目ZIP解压根目录含project.config.json，直接导入微信开发者工具；不要叠加解压到旧项目。使用自己的AppID。本地运行不需要云环境、云登录、支付或业务服务器。所有工具免费，移除签到、容量兑换和喵铺入口，保留日常问候。

在仓库根运行：

```powershell
# 首次准备：替换为自己已安装微信开发者工具的路径
python wechat/tools/extract-wechat-terser.py "wechat-devtools/resources/app.asar"
node wechat/tools/build-local-variants.cjs
node --test wechat/tests/*.test.cjs
```

构建输出为仓库根目录下的`test-results/local-builds/local-source/`（可编辑）和`local/`（压缩），用微信开发者工具导入其中一个目录并替换自己的AppID。首次下载和分包获取由微信提供，业务资料保存在手机。源码保留历史兼容实现，正式发布应使用裁剪后的构建目录。

可选排版检查为`node wechat/tools/verify-local-layout.cjs`及`node wechat/tools/verify-local-me-layout.cjs`，依赖Playwright与脚本所指定的本机浏览器路径。`package-local-first.py`复刻2026-11-06交付档案，需要当日测试记录，不是日常开发的前置步骤。

构建默认仅生成local和local-source。过渡构建被明确禁用。首次构建参考tools/extract-wechat-terser.py，提取已安装微信工具的Terser。4项生成项目回归依赖先构建。本轮无需后端更新；源码中保留的旧云端代码与回归仅作历史维护，发布包通过依赖裁剪移除它们。

首次进入会展示新的公告，并可从公告入口重看。通知说明：使用人数较少，产品停止提供云端存储；这次不迁移原云端资料，旧物品、账目、照片不在新版显示，也不会自动保存到手机；对此道歉并请求理解。从本版起资料保存在当前手机，所有工具免费，不自动上传或跨设备同步。

通知不声称云环境已经销毁或资料已经永久删除；云资源操作以实际控制台结果为准。已有本机资料和可恢复备份不会被清空；没有本机资料时使用新本地资料库。作者已确认本地版上线，不代表所有设备文件流程均已测试。

## 日常备份与恢复

本地版免登录，不自动跨设备同步。用户平时直接记录，不需要反复迁移或提交。可在“我的 → 资料与完整备份”生成ZIP、分享并保存到小程序之外，核实后确认已外部保存。取消分享不算已备份。

ZIP包含个人资料、历史与照片，默认不加密，请妥善保管。卸载、清理微信或换手机前应先外部备份。导入预览和校验后先备份当前资料，再明确确认整库替换，不合并；失败保留原资料。内部恢复副本不能代替外部备份。

## 我的页面更新

“我的账本”和“月度预算”已移入下方“工具与设置”菜单，与其他入口保持同样样式并常驻显示，删除折叠与偏好记录逻辑。资料备份入口移至所有菜单下方，采用横向状态栏，读取当前资料库的外部备份状态。只生成但未确认外部保存的ZIP不会显示为已备份；读取失败单独显示，不误报从未备份。点击进入原备份、空间及恢复管理页。

## 临时备份清理

导出ZIP不永久堆积：确认已保存到聊天、电脑等外部位置后，自动删除小程序内对应的ZIP。未确认的导出正常只保留最新一份供发送重试，新包生成成功后替换旧临时包；生成失败保留上一份。分享进行中不清理，取消分享不记作外部保存。

“本机空间”增加“清理临时备份包”，可删除当前资料库的导出ZIP、失败的partial及打包用临时JSON。清理不删除物品、账目、照片、聊天中的文件或内部恢复版本。清理失败会提示重试，不会把已确认的外部备份记录清掉。小程序里的备份日期记录不是备份文件本身，外部文件仍须自行保管。
