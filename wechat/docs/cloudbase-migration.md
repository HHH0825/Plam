## 1. 部署包

文件位于 `wechat/deploy/cloudbase/`：

- `palm-api-python310.zip`：Python 3.10 Linux x64；Gunicorn 单工作进程、4 线程、端口 9000。根目录含 `app.py`、可执行且使用 LF 换行的 `scf_bootstrap`、`palm/`、共享 HTTP 客户端和 `third_party/`。
- `palm-api-bridge-node20.zip`：Node.js 20 普通函数，执行方法 `index.main`，锁定 CloudBase Node SDK 3.18.3。
- 两个 `.sha256` 文件用于核对包完整性。包中不包含 SQLite、照片、密钥、测试路由或测试运行器。
- `resources.json`：环境、正式集合、索引、函数及验收后清理清单；COS 域名和单账号实际上传下载已验证，多用户与费用门槛另见最新验收记录。
- `api/env.example.json` 与 `bridge/env.example.json`：需要在控制台填写的环境变量模板，**模板占位内容不能直接用于上线**。

重新构建（从项目根目录执行）：

```powershell
Set-Location .
Set-Location wechat\deploy\cloudbase\bridge
npm ci --omit=dev
Set-Location ..\..\..\..
.\wechat\.venv\Scripts\python.exe wechat\deploy\cloudbase\build.py
```

依赖固定在部署目录的 `api/requirements.txt`。Windows 本机 Pillow 为 12.3.0，而部署使用存在 Python 3.10 Linux wheel 的 12.2.0；图片处理必须在部署后再次验证。不要上传 Windows 虚拟环境或 `.pyd` 文件。

## 2. 准备正式集合与索引

保留数据库实例 `tnt-example`。服务端 HTTP API 使用之前实际验证成功的 `(default)` 实例和 `(default)` 数据库。

按 `resources.json` 创建 13 个正式集合，名称必须完整保留 `palm_` 前缀。每个集合的客户端数据权限选择 **无权限 `[ADMINONLY]`**。这仍允许服务器管理员访问；小程序不直接读写集合，而通过已验证会话访问 Flask。

在“索引管理”按资源清单创建组合索引，各字段升序且顺序与清单相同。唯一约束依赖系统 `_id` 索引：微信身份、归一化昵称、请求回执都使用稳定摘要作为 `_id`；数字 ID 计数器和业务变更在同一事务中提交。不要手工填用户或物品初始数据。

集合读取检查可使用 `readiness.py`，只检查缺失配置与服务器读取能力，不创建资源、不写数据、不输出密钥。读取成功不能证明客户端权限设置正确，仍需控制台核对 ADMINONLY。

```powershell

```

## 3. Python 正式函数

在网页版 CloudBase 控制台创建 **`palm-api`，HTTP 云函数，Python 3.10，端口 9000**。上传 Python ZIP 后，填写 `api/env.example.json` 所列环境变量，再部署。初始内存 256 MB，执行超时 60 秒；不要开启 VPC、固定出口 IP、预置并发或购买套餐。内存与超时需按真实冷启动及照片测试核对用量，遇到付费门槛停止该步骤。

`PALM_STORAGE_BACKEND=cloudbase`，`PALM_WECHAT_DEV_LOGIN=0`。缺少正式配置时服务必须启动失败或返回明确错误；不回退 SQLite。云函数本地文件只作为运行依赖，正式数据写入 CloudBase。

管理员 API Key 是 **服务端 API Key，管理员权限**，不是小程序发布密钥。名称建议 `palm-api-prod-YYYYMMDD`，90 天过期；与测试 Key 分开。只在服务端环境变量填写，不发到聊天、不放进 `config.js`、不保存到版本库。AppSecret 对应项目 AppID `touristappid`。

具体填写步骤：

1. 网页 CloudBase 选择本环境 → 环境管理/环境配置 → API Key 管理 → 服务端 API Key → 创建。名称可用 `palm-api-prod-20261006`，有效期 90 天。保存到你自己的密码管理器；明文通常只在创建时出现一次。创建入口详见 [官方 API Key 说明](https://docs.cloudbase.net/http-api/basic/apikey)。
2. 登录微信公众平台，进入本小程序的“开发设置”（通常在“开发管理”下），核对 AppID 后获取 AppSecret。平台如要求扫码或管理员验证，由你本人完成。
3. 打开正式 `palm-api` → 函数配置 → 编辑 → 环境配置 → 环境变量。新 Key 填入 `CLOUDBASE_API_KEY`；AppSecret 填入 `PALM_WECHAT_APP_SECRET`；AppID 填入 `PALM_WECHAT_APP_ID`。其余逐项按模板填写，保存并部署。
4. Node `palm-api-bridge` 只填写 Node 模板变量，两函数 `PALM_BRIDGE_SECRET` 保持一致。不要给小程序填写这三项密钥。

微信开发者工具的服务端口已由用户开启，官方 CLI 已成功上传普通 Node 函数。本机版本 CLI 上传 Python 时要求 `index.js` 而拒绝；Python 代码上传和更新使用网页版。CLI 上传路径末级文件夹名必须与正式函数名一致，不能直接把名为 `bridge` 的文件夹当成 `palm-api-bridge` 上传。不要使用 Node.js 创建后再上传 Python 包。

转发密钥由密码生成器生成至少 32 字符的随机值，Python 与 Node 环境变量保持一致。不要使用 AppSecret 或管理员 API Key 充当转发密钥。

HTTP 网关添加 `/palm` 路由，关联 `palm-api`，启用路由、关闭路径透传；该前缀由网关去掉。Python 的 `/healthz` 可用于就绪检查，业务 `/api/mp/*` 必须携带内部转发密钥及用户会话。不要把转发密钥放在地址栏。

正式内部地址为现有网关域名下的 `/palm/`。`/flask-check` 保留供对照，验收前不删除。

## 5. 私有照片与域名

现有桶：`636c-cloud1-example-1000000000`。从云存储配置/实际上传信息核对默认 COS 域名，登记到小程序的 `uploadFile` 和 `downloadFile` 合法域名，必要时同时登记二进制 PUT 所用的 `request` 合法域名。本实现用 `wx.request` 上传二进制，不经普通云函数转发图片。无需购买域名。

先核对存储客户端权限为仅管理员可读写；不要通过开放全部读写解决照片错误。真实设备开启域名校验，确认该默认域名能够使用，再接入正式照片流程。

- 申请上传凭证绑定当前用户、物品、随机临时路径；实际 COS 上传签名必须在十分钟内过期，代码会检查签名时间，未知或过长时返回错误并阻止下发。
- 只有 JPEG、PNG、WEBP 且输入不超过 5 MB；后端解码、校正方向、清除元数据、转 JPEG。完整图最大边长 1600、512 KB，缩略图最大边长 480、80 KB。
- 完整图和缩略图都上传成功，才能在事务中更新物品；失败候选文件、替换旧文件和临时文件进入持久清理队列。
- 直连下载先检查物品归属，由 Python 获取下载信息并校验实际签名最长五分钟。Node 签名只保留在旧转发兼容路径；正式请求不会调用 Node。当前云端照片关闭，实际凭证申请返回业务 503，日志已确认 `PHOTO_UPLOAD_TTL_UNVERIFIED`。

**经典云存储上传接口文档未列出有效期入参；当前实际返回凭证未通过十分钟有效期检查，代码已拒绝下发。照片仍停在接入步骤，需要核验平台短期签名能力，并避免凭证和下载签名进入平台响应正文日志；不能宣称照片验收通过。**参考 [官方上传信息 API](https://docs.cloudbase.net/http-api/storage/get-objects-upload-info) 和 [小程序 COS 域名配置](https://cloud.tencent.com/document/product/436/122402)。

## 6. 回收站及分批清理

三十天过期立即从列表隐藏、拒绝恢复，不依赖清理任务执行时机。物理删除先写过期标记并将物品置为清理中，逐批删除维修、处置、历史记录和照片；失效照片删除失败保留队列，重试间隔从五分钟逐步增加至最多一天。失败也计入处理上限，其他文件及过期会话继续清理；日志仅记录脱敏错误码、请求编号和次数。每次有记录数和二十秒时间上限，不在启动时扫描全库。

已提供清理入口 `python -m palm.cloud_maintenance`，在配置好上述正式环境变量的维护环境运行（工作目录 `wechat/backend`）。一次最多处理 40 项逻辑操作，多次运行直至队列清空。输出仅包含处理数量；如报错，通过脱敏错误码定位，不能打印环境变量或签名 URL。

**本阶段采用人工分批清理，不部署自动触发器。**按直连说明在可信维护环境执行上述入口，检查失败重试队列。过期隐藏通过不代表物理清理完成；当前大批量清理仅在模拟服务中验证。

## 8. 用量及密钥轮换

直连的一次业务请求调用 Python HTTP 函数，正式小程序停止调用普通转发函数；旧转发模式一次业务请求仍涉及两个函数。JSON 重试和冷启动也增加调用与执行时长。文档读写按实际 API 操作计算，复杂操作包含多次读取与事务操作；函数调用次数不能视为数据库操作次数。费用管理页面的按量付费、自动续费开关已只读核对为关闭；最新实际调用及存储总用量仍待核验，不能据此宣称长期免费或始终在额度内。

在正式 Key 到期前至少七天轮换：创建同权限的新正式 Key → 更新 Python 环境变量并部署 → 验证真实登录、读写、照片 → 确认旧 Key 无其他引用 → 经用户授权撤销旧 Key。测试 Key 单独清理。转发密钥需协调更新两函数，期间客户端保留未确认请求标识；上线前完成基础调用验证。
